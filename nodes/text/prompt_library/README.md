# Библиотека промптов — TS Prompt Library

Данные ноды **TS Prompt Library**. Код их не знает по именам: раздел, модель и
пресет находятся по папкам, поэтому добавление — это новый JSON, а не правка кода.
Правила чтения — `nodes/text/_prompt_library.py`.

## Устройство

```text
prompt_library/
  context_edit/                 раздел
    section.json
    qwen_image_2_1/             коллекция — промпты под одну модель
      collection.json
      previews/                 (необязательно) картинки к пресетам
        R01.webp
    flux2_klein_9b/
      collection.json
  video/                        следующий раздел — просто новая папка
    section.json
    wan_2_2/
      collection.json
```

Ключ пресета в сохранённом графе — `раздел/коллекция/ID`, например
`context_edit/qwen_image_2_1/R01`. **Папки и `id` пресетов после публикации не
переименовывайте**: граф, сохранённый со старым ключом, перестанет находить пресет.

Имена папок и `id`: латиница, цифры, `_ . -`, до 64 знаков.

## section.json

```json
{
  "schema": 1,
  "title": {"ru": "Контекстное редактирование", "en": "Context editing"},
  "summary": {"ru": "...", "en": "..."},
  "order": 10
}
```

`order` — место в списке (меньше — выше). Папка без `section.json` разделом не считается.

## collection.json

```json
{
  "schema": 1,
  "title": "Qwen Image 2.1",
  "model": "Qwen Image 2.1 Edit",
  "order": 10,
  "references": "<image1>, <image2>",
  "summary": {"ru": "...", "en": "..."},
  "guide": {"ru": ["шаг 1", "шаг 2"], "en": ["step 1", "step 2"]},
  "source": {"title": "...", "url": "https://...", "edition": "2026-09-27"},
  "placeholders": {
    "TARGET": {"label": {"ru": "Конкретный объект или область", "en": "A specific object or region"},
               "example": "the red suitcase beside the left chair"}
  },
  "groups": [
    {"id": "removal", "title": {"ru": "Удаление", "en": "Removal"}, "presets": [
      {
        "id": "O02",
        "title": {"ru": "Удаление выбранного объекта", "en": "Removing a chosen object"},
        "inputs": 1,
        "summary": {"ru": "...", "en": "..."},
        "prompt": "Remove {TARGET} completely from the image, ...",
        "examples": {"TARGET": "the red suitcase beside the left chair"},
        "note": {"ru": "...", "en": "..."},
        "links": [{"title": "...", "url": "https://..."}],
        "preview": "previews/O02.webp"
      }
    ]}
  ]
}
```

- Текстовые поля — строка или `{"ru": ..., "en": ...}`; интерфейс берёт язык ComfyUI,
  при отсутствии — английский.
- **Поля подстановки** — `{ЗАГЛАВНЫМИ}` в промпте. Каждое обязано быть объявлено в
  `placeholders` коллекции (подпись и общий пример). `examples` пресета заменяет
  общий пример там, где тот сбил бы с толку. Строчные фигурные скобки полями не
  считаются.
- `inputs` — сколько изображений подать (0–8); показывается значком на карточке.
- `preview` — путь **внутри папки коллекции**, картинка `png/jpg/webp/gif/avif`.
  Карточка покажет её над промптом. Путь за пределы коллекции не подключится.
- Коды задач лучше держать одинаковыми у коллекций одного раздела: при смене модели
  нода остаётся на той же задаче.

## Что нода не примет

Кривой пресет не подключается — с объяснением в журнале ComfyUI
(`[TS Prompt Library] ...`): пустой промпт, необъявленное поле, неверный `id`,
повтор `id` в коллекции, `inputs` вне 0–8, `schema` не 1, битый JSON. Лучше
отсутствующий пресет, чем промпт, ушедший в модель с буквальным `{TARGET}`.

Правки JSON подхватываются без перезапуска ComfyUI: нажмите **R** на холсте.

## Откуда взялся раздел context_edit

- `qwen_image_2_1` — авторский каталог «Qwen Image 2.1 — 50 промптов для
  контекстного редактирования» (редакция 27.09.2026), промпты перенесены дословно.
  Исключение — **O13** (удаление фона, объект модель находит сама), дописан
  01.10.2026 по O12 и официальной формуле прозрачности из README
  QwenLM/Qwen-Image-2.1; в его примечании это сказано.
- `flux2_klein_9b` — те же 50 задач, переписанные по правилам Black Forest Labs для
  FLUX.2 (docs.bfl.ml: входы словами «image 1», без негативного промпта, явный
  перечень того, что сохраняется). Визуальные прогоны на конкретных снимках не
  выполнялись.
