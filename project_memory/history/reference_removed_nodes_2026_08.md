# Снятие 16 нод, 11 августа 2026 (v10.1.0 → **v11.0.0**)

Решение владельца пака. Старшая цифра версии — потому что чужие сохранённые
графы, где эти ноды стоят, перестают открываться целиком: это ровно тот случай,
для которого мажорный номер и существует.

Было 79 → стало **63**. По папкам: image 42→33, files 8→2, video 9→8; остальные
не изменились.

## Архив — `archive/removed-nodes-2026-08-11.zip`

588 КБ, 81 файл: код (с сохранением путей), встроенная справка, снимки нод,
разделы README обоих языков, записи `locales/ru/nodeDefs.json`, снимок их
контрактов, задетые тестовые файлы целиком и два примера-воркфлоу. Внутри —
`ВОССТАНОВЛЕНИЕ.md` с порядком возврата.

Для восстановления использовать **историю Git**, а не память: локальный zip — лишь удобная копия и в чистом клоне отсутствует. Снимок снятого кода доступен в [коммите bc20a1d](https://github.com/AlexYez/comfyui-timesaver/tree/bc20a1d).

## ⚠️ Настоящая копия снятого — история git, а не архив

`archive/removed-nodes-2026-08-11.zip` лежит в `.gitignore` СОЗНАТЕЛЬНО. Всё, что
в нём есть, было под контролем версий до удаления, поэтому возврат делается так:

```bash
git checkout bc20a1d -- nodes/image/keying nodes/image/ts_color_grade.py
```

`bc20a1d` — последний коммит, где ноды ещё на месте. Zip — лишь удобная копия на
диске; в репозиторий он не берётся, потому что навсегда осел бы в истории, уехал
бы в дистрибутив (zip реестра собирается из `git ls-files`, `.comfyignore` в паке
нет с v9.14) и попал бы в чекаут, который читает сканер безопасности реестра.

## Хвосты, которые тянутся за таким удалением

Аудит 11.08.2026 нашёл их уже ПОСЛЕ основной чистки — список стоит пройти
целиком, если снимаешь ноду:

1. **Зависимость без потребителей.** `py360convert` остался в `requirements.txt`,
   `pyproject.toml` и в подсказках `ts_dependency_manager` — его ставил каждый
   пользователь пака. Проверять надо не «есть ли импорт в ноде», а обход всего
   дерева.
2. **Заголовки секций в тестах** без единого теста под ними.
3. **Комментарии со ссылками на удалённые файлы** (`See ts_film_grain.py`).
4. **Примеры команд в инструкциях** (`screenshot_nodes.py TS_Keyer`).
5. **Списки «не переименовывать»** с именами снятых нод.
6. **Записи памяти**, перечисляющие ноды по именам.

## Чего это коснулось, кроме кода (список неочевидного)

Удалить файл ноды мало. Пришлось трогать:

1. `locales/ru/nodeDefs.json` — 78 записей → 62.
2. Оба README: 16 разделов `#### …`, счётчики в шапках категорий, счётчик нод в
   подзаголовке, строка про состав `nodes/` в карте репозитория.
3. `js/docs/` — папки справки. Генератор их **не убирал**: снятая нода оставляла
   за собой страницу, и ComfyUI показывал справку по тому, чего в паке уже нет.
   Теперь `tools/build_node_docs.py` сам удаляет осиротевшие, а `--check` на них
   падает.
4. Тесты — 42 функции и фикстуры в пяти файлах, вперемешку с живыми; плюс
   шапки-докстринги, где ноды перечислены поимённо.
5. `tools/build_example_workflows.py` — **рецепты примеров живут там**, а не в
   JSON. Пример «resize/grade/grain» был целиком на снятых нодах, заменён на
   «Trim a video and save it» (три новые видео-ноды). В примере с плитками
   `TS_Color_Grade` заменён на `TS_Film_Emulation` — роль та же.
6. `CLAUDE.md`, `doc/ARCHITECTURE.md`, `project_memory/project_overview.md`.

## Переименования (только видимое имя, идентификаторы нетронуты)

- `TS_Qwen3_VL_V3`: «TS Qwen 3 VL V3» → **«TS Qwen 3»**
- `TS Files Downloader`: «TS Files Downloader (Ultimate)» → **«TS Files Downloader»**

`node_id` у обеих прежний, поэтому сохранённые графы не задеты. ⚠️ Заголовок
`#### …` в README обязан совпасть с новым `display_name` — иначе генератор
справки не находит раздел и молча кладёт вместо него голое описание из схемы.

## Студия — вне справки, и это не недоделка

`NO_HELP` в `tools/build_node_docs.py`: `TS_ImageStudio`, все `TS_Studio*`,
`TS_LangevinInpaint`, `TS_UniversalInpaintSampler`. Главная нода вернётся в
справку, когда студия будет готова; **служебные не вернутся никогда** — их никто
не вытаскивает на холст осознанно.

## ⚠️ Папка справки называется по `node_id`, а не по отображаемому имени

ComfyUI ищет `js/docs/<node_id>/<локаль>.md`. Страницы, написанные руками в
папках вида `js/docs/TS Video Loader/`, не находились никогда — их просто не
показывали. Ловится это только сверкой с контрактами, что генератор теперь и
делает.
