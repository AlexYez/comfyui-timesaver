# Аудит пака 29.09.2026 (после 12.11.8)

Метод: skill `ts-comfyui-nodes-audit`; пять проверяющих параллельно (безопасность,
исполнение, фронтенд, совместимость/метаданные, разбор нового кода), каждую
находку перепроверял по коду ядра. Живой сервер: 82/82 ноды, описания у всех,
ru-локаль и справка отдаются, 11 шаблонов + тестовый граф Qwen открываются во
фронтенде. Безопасность — новых P0/P1 нет.

## Исправлено (все — с тестами)

- **TS NAG** — LTX-2 негатив мимо коннектора; fp8; проход одного негатива.
  Подробно: [reference_nag](../engineering/reference_nag.md).
- **TS LoRA Unmerged** (новая, невыпущенная) — ~6 ГБ VRAM на удержание gate_up
  всех блоков; fp8 A/B; DoRA; кортежи Flux; метаданные PEFT. См. [reference_qwen21_turbo](../engineering/reference_qwen21_turbo.md).
- **TS Shifted Sigmas / TS Video Cut** — `**kwargs` в `validate_inputs` выключал
  у ядра min/max ВСЕХ входов (`execution.py`, `validate_has_kwargs`). ⚠️ Это же
  выключает проверку списка комбо — у 9 выпущенных нод (Qwen 3, RT Enhancer,
  LaMa, SAM, Image Resize, RTX, Audio Preview, обе Silero) `**kwargs` ОСТАВЛЕН
  намеренно: строже = риск, что старый граф не откроется. Правило — в CLAUDE.md §9.
- **DLSS** — исключение v5→v9 только один раз (нет `dlssnr/`, признак `host/`),
  без сети — понятная ошибка.
- **TS Video Saver** — RGBA/серый (альфа только в ProRes 4444/XQ), недописанные
  файлы при ошибке/отмене удаляются (ТОЛЬКО созданные этой записью), сбой EXR
  больше не глотается превью.
- **TS RTX Upscaler** — отмена и прогресс по кадрам.
- **TS Compare** — кадры по одному (было 3 копии float32 всей пачки), после
  F5 результат снова виден, окно закрывается с нодой.
- **TS Video Loader** — горячие клавиши во весь экран срабатывали дважды
  (оверлей на window + постоянный слушатель на document).
- **TS Prompt Library** — у `preset` нет было гнезда (hideWidget снимал его);
  `hideWidget(node, name, {keepInput:true})` — НОВАЯ опция общего модуля.
- **Super Prompt/RT, Angle Select** — `api.fetchApi`/`api.apiURL` вместо путей
  от корня; `forceContextLoss` у WebGL. `_dnd.js`: видео ссылкой — видео.
- **Шаблоны**: 06 (путь `D:\...\output` с машины автора), 08 (VAE ACE-Step
  вместо LTX, наложенные ноды), 11 (SAM3 в загрузчике чекпойнтов). ⚠️ Причина —
  генератор сохранял умолчания, вычисленные на машине: теперь
  `strip_machine_paths` в `tools/build_example_workflows.py`. Миниатюры 06/08/11
  пересняты с подменой списка моделей ТОЛЬКО в странице (иначе тост «missing
  model» и красная нода на картинке).
- ru-локаль: `display_name` не переводим (было 17), outputs у HDR и Universal
  Inpaint; README-числа; `packaging`; публикация только при смене версии;
  снимок контрактов с `effective_widget_order` + сторож «старый порядок —
  префикс нового» против последнего `release:`.
