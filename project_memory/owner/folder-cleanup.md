Уборка означает перенос согласованных остатков в игнорируемый архив, а не удаление данных.

## Требование 2026-11-02

> Nothing is deleted: archiving can be undone, deletion cannot.

> Show me the list grouped by reason, together with what you plan to keep, and wait for my go-ahead before moving anything.

Сначала показать для каждого кандидата путь, размер, дату и причину; искать потребителей и ссылки. Source, tests, конфигурация, текущая документация и память остаются. Секреты и личные данные не переносить в архив. Regenerable output не архивировать; размер больших моделей/установщиков сначала сообщать.

После подтверждения — `archive/YYYY-MM-DD/` с сохранением исходных относительных путей, MANIFEST и возможностью восстановления. Для внешних файлов — подпапка external с местом происхождения. Архив должен быть исключён из Git до переноса. Если ignore-правило требуется добавить, его отдельный коммит должен предшествовать архивированию. На момент запроса `/archive/` уже содержалось в HEAD.

Слитые временные ветки и worktree проверять через Git по отдельности; при уборке branch-ссылки сохранять восстанавливаемый SHA/backup. Не удалять backup-ветки, которые Git не подтверждает как слитые. После переноса проверять затронутое поведение и ссылки, сломавшийся элемент восстанавливать.

## Уточнение по крупным остаткам в этой партии

На предложение оставить тестовую Whisper-модель, архив/распакованный v21 и резервные VFX DLL владелец ответил:

> Почему не включаешь? Включай! Нужно всё лишнее собрать и сложить папку в архив.

Это разрешает включить указанные крупные остатки в рассматриваемую партию. Следующее отдельное указание заменило судьбу распакованного v21: его нужно поставить внутрь установленного пака и сделать относительные пути. Оно выполнено отдельно; v21 больше не архивный кандидат.

Полный список владелец подтвердил 2026-11-02 ответом «да». [Уборка выполнена](../../doc/maintenance/CLEANUP_RESULT_2026-11-02.md): 108 пунктов, 4 890 684 011 байт; файлы сохранены в локальном архиве с SHA256/манифестом. Ветка image-studio сохранена полной bundle-копией перед удалением слитой ссылки. 225 связанных тестов прошли, сломавшихся элементов не выявлено. Это завершённая партия, не постоянное разрешение архивировать новые находки без следующего согласования.
