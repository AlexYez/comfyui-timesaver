Не поднимать версию в pyproject.toml без ведома пользователя — версию назначает он

**Версию в `pyproject.toml` не трогать по своей инициативе.** Ни при добавлении
ноды, ни при релизной записи в CHANGELOG, ни «за компанию» со значком в README.

Так было 14.08.2026: за одну сессию версия уехала 12.0.0 → 12.1.0 → 12.2.0, оба
раза по моему решению. Когда работа была свёрнута, всё это пришлось откатывать
вручную — вместе со значками в обоих README и заголовками разделов CHANGELOG,
которые на неё ссылались.

**Почему.** Версия — это обещание пользователям пака: она уезжает в Comfy
Registry, по ней люди понимают, что обновилось. Решение о номере — владельца,
не помощника. Незаявленный номер ещё и путает: релиз, которого не было, уже
описан.

**Как применять.** Код, справку, CHANGELOG-запись писать можно; номер версии —
спрашивать. Если запись в CHANGELOG нужна до того, как номер назначен, ставить
заголовок вида `## Unreleased` и явно сказать об этом в ответе.

## Словарь бампов (согласован 08.09.2026)

Владелец спросил, каким словом просить последнюю цифру. Договорились так —
одного слова достаточно, дальше я делаю всё сам (`pyproject.toml`, раздел
CHANGELOG, коммит, пуш):

| Слово владельца | Что двигается | Пример из 12.7.1 |
| --- | --- | --- |
| **патч** (багфикс) | последняя цифра | 12.7.2 |
| **минорный** | средняя, последняя в ноль | 12.8.0 |
| **мажорный** | первая, остальные в ноль | 13.0.0 |

Мажорный — только при сломанной совместимости (убран `node_id`, изменились
входы или порядок выходов); см. [feedback_compatibility](feedback_compatibility.md).

Правило выше при этом не отменяется: **сам номер не назначаю**. Слово владельца
или прямая цифра («12.6.1» — так он уже делал) — обязательное условие. Если
номера нет, а запись нужна, заголовок `## Unreleased`.
