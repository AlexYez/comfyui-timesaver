# Полный набор тестов: час → меньше 5 минут (28.09.2026)

Просьба владельца: «полное тестирование не больше 5 минут». Разрешил ставить
пакеты — поставлен `pytest-xdist` 3.8 в ComfyUI-овский Python.

## Замер (до правок)

- Последовательно: ~42 мин чистого времени (прошлый час раздула чужая задача
  на GPU). 142 файла, ~3620 тестов.
- Первый тест почти каждого файла — 11–13 с: импорт torch/ComfyUI на процесс.
- Браузерные (30 файлов, Playwright против живого сервера) — 31 мин подряд,
  потому что переключают серверную настройку `Comfy.VueNodes.Enabled`.
- Один тест `test_inpaint_crop` — 185 с: не тест медленный, а КОД (см. ниже).

## Что сделано

| Шаг | Где | Эффект |
|---|---|---|
| `-n 16 --dist loadgroup` | `tools/preflight.py` | импорт один раз на процесс |
| перехват `/api/settings` на каждый контекст | `tests/conftest.py` (`_isolate_settings`) | браузерные тесты параллельно; настройки владельца не трогаются |
| `xdist_group` для дорогих фикстур-сценариев | `conftest.py` (`_SHARED_SCENARIOS`, хук `tryfirst`) | `tidied/routed/packed` и др. считаются один раз |
| basetemp в `tests/.cache/pytest` | `conftest.py` (`pytest_configure`) | xdist падал на `%TEMP%` (WinError 5) |
| свои папки по `PYTEST_XDIST_WORKER` | 4 файла downloader/async | общие папки давали WinError 32 |
| ожидание готовности вместо паузы 5–8 с после goto | 24 места в 6 файлах | и быстрее, и нет «app is not defined» под нагрузкой |
| `test_tooltips` на 6 частей | параметр `chunk` | 85 с одним куском → ~30 с частью |
| дилатация маски разделимо + удвоением окна | `nodes/image/_inpaint_crop.py` (`_dilate`) | 185 с → 0,25 с, бит в бит (TS Smart Inpaint у пользователей тоже) |

Итог замеров: 5:32 → 4:46 → 4:29 → **4:10 весь `preflight.py --full`**
(3627 passed, 41 skipped, pytest 247 с; 24 ядра, 16 процессов, ComfyUI запущен).
Пропуски — те же ~41, что и при последовательном прогоне.

## Грабли, которые вскрыла параллельность

- ⚠️ Хук `pytest_collection_modifyitems` с отметкой группы ОБЯЗАН быть
  `tryfirst=True`: xdist читает `xdist_group` в своём хуке, и отметка, поставленная
  позже, не действует — сценарии пересчитывались на каждом процессе.
- ⚠️ Модульная фикстура под `--dist load` пересоздаётся каждым процессом, который
  вытянул хоть один её тест (и снова — при возврате к модулю). Дешёвая загрузка
  страницы — пусть; сценарий на минуту — только в группу.
- Шум ядра `[Jobs API] … Failed to fetch` (запрос очереди, оборванный
  перезагрузкой) под нагрузкой всплывает чаще — фильтры консоли его отсеивают.
- Сторож «бинарники не в паке» сканировал `tests/.cache` и находил поддельный DLL
  соседнего теста — временная папка тестов исключена.
- Самый долгий одиночный тест задаёт нижнюю границу всего прогона — такие
  дробить (как `test_tooltips`), а не только параллелить.
