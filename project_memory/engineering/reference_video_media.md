Видео-ноды: текущая карта backend/UI и датированная история PyAV, таймлайна и звука.

Публичные видео-ноды находятся в [nodes/video/media](../../nodes/video/media/). Запись ролика выполняется backend-кодом, а обновление preview — отдельная frontend-задача. При диагностике проверяйте новый файл, а не только UI. Для памяти декодера используйте отдельную [запись](reference_video_loader_memory.md): старое фиксированное значение 8 ГиБ в истории не описывает нынешний расчёт.
