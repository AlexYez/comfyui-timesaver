31.10.2026 live comparison LFM3 VL/Omni, Gemma LiteRT E2B/E4B, Qwen3.5 2B/4B; Qwen EOS bug fixed

Исходники темы: [_qwen_engine.py](../../nodes/llm/_qwen_engine.py).

**Граница записи:** ниже сохранены исходные наблюдения и причины решений. Замеры, версии окружения и слова «сейчас» относятся к дате соответствующего наблюдения; это не повторная проверка на новом окружении. Порядок чтения и ограничения: [инженерная память](README.md#как-читать-записи).

Пользователь прямо разрешил перезапустить ComfyUI и сравнить шесть локальных
моделей на русском исходном запросе с системными промптами LTX и MiniMax.
Сервер перезапущен для новых нод, затем ещё раз для выявленного EOS-исправления.
Это разрешение относится к этой задаче; правило «не перезапускать без прямой
команды» по-прежнему действует для будущих задач.

Итоговые артефакты (локальные, gitignored):

- `dist/llm-comparison-2026-10-31/index.html` — обзор.
- `comparison.html` и `compact/comparison.html` — 12+12 дословных ответов,
  инструкции и критические замечания. Рядом JSON и API-графы.
- Тестовые скрипты и полные истории:
  `tests/.cache/llm-comparison-2026-10-31/`.
  `before-eos-fix/` в обоих раундах содержит старые ответы Qwen.

Шесть моделей: LFM3 VL heretic, LFM3 Omni Uncensored, Gemma 4 LiteRT E2B/E4B,
Huihui Qwen3.5 2B/4B abliterated. Веса Qwen9B не скачаны и не тестировались.
Один русский сюжет: женщина в тёмно-зелёном плаще, станция после дождя,
закрывает красный зонт, говорит «Я знала, что ты вернёшься.», 8 секунд,
медленный небольшой наезд, дождь/шелест, без музыки/текста/субтитров.

Сначала применены неизменённые рабочие пресеты (LTX 8260 знаков, H3 9477).
Пять из шести LTX-ответов дописали Nobody speaks после речи. Ни один из
шести не выполнил все требования обеих инструкций без ошибок.

Контроль: короткие общие инструкции на все шесть моделей, тот же исходник,
seed42, лимит1024, без картинок/аудиофайлов. Nobody speaks исчезло во всех
шести. Русские реплики сохранялись лучше, но H3-формат нарушался у всех.
Рабочие файлы пресетов НЕ редактировались. Custom sampling отличается от
пресетов, поэтому это не строгая абляция длины инструкции и не общий рейтинг.

Текущие наблюдения ТОЛЬКО по этому примеру:

- Gemma E2B: короткие LTX/H3 ~9/9 секунд, хороший компактный сюжет и дословная
  реплика, но нет требуемых [Russian]/(S1)/native-Russian формулировки.
- Gemma E4B: ~11/11, LTX повторяет одну реплику дважды; H3 теряет теги.
- LFM3 VL: ~21.4/19.9, короткий LTX сохраняет практически все факты, есть
  лишний метатекст; H3 теряет <d>/[Russian]/S1.
- LFM3 Omni: ~20.4/20.9, во всех четырёх ответах меняет красный зонт на шляпу.
  Даже короткий H3 меняет ё на е, теряет формат. Не выдавать её за доказанно
  лучшую модель для русских видеопромптов на основании рекламных бенчмарков.
- Qwen2B после EOS-фикса: короткий LTX18.64 с, H3 25.45 с. LTX в целом
  хороший; H3 создаёт неверный foreign-блок и дублирует реплику.
- Qwen4B после EOS-фикса: короткий LTX40.92 с, H3 27.02 с. Первый содержит
  лишние инструкции о самом промпте, второй сваливает поля в один блок.

Время — полный Run с загрузкой и выгрузкой, не чистый decode. Все TF-модели
BF16, Gemma — её существующий LiteRT-формат. Память в отчёте — пик всей GPU
(nvidia-smi/500ms), а не весов. Один seed не даёт статистического рейтинга.

### Реальный баг Qwen, выявленный в тесте

У обеих локальных Huihui Qwen3.5 config.text_config.eos_token_id=248044
(<|endoftext|>); generation_config 4B тоже248044, у2B этот файл отсутствует.
Но tokenizer.eos_token_id=248046 (<|im_end|>). 4B после первого ответа
продолжала user/assistant до1024 токенов; короткий LTX занял85.77с.

Исправлено в общем `nodes/llm/_qwen_engine.py`: `sync_chat_eos(model, processor)`
добавляет EOS токенизатора к существующим EOS в in-memory generation_config
перед помещением модели в кэш. Работает и для TS Qwen 3, и для Super Prompt;
модельные файлы на диске не меняются. Тесты проверяют сохранение старых EOS,
идемпотентность, отсутствие метаданных и реальную остановку маленького GPT2
после первого chat-end. 74+85=159 целевых тестов прошли под ComfyUI Python.
Исправление синхронизировано в установленный пак. Все восемь Qwen-запусков
повторены; только повторные ответы входят в итоговую таблицу.

24 текста проверены: 8 по живой истории после рестарта, 16 по сохранённым
непосредственно из API raw history JSON (история очищается при рестарте).
HTML-таблицы и ссылки проверены Playwright через установленный Edge headless
с отдельным профилем; браузер закрыт. Встроенный Playwright Chromium на машине
отсутствует — не скачивали. Сервер оставлен запущенным с пустой очередью.
Версию не поднимали, commit/push пользователь в этой задаче не просил.
