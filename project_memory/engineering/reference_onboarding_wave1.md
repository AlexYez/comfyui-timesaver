# Волна 1: пак объясняет себя (коммит `a00e9cf`)

Синтез двух исследований (архитектура ComfyUI на конец июля 2026 + UX-ревью
фронтенда). Всё — метаданные и статика: контракты нод не тронуты,
`node_contracts.json` без дрейфа (61 нода).

## Что появилось

- **`description=` у 43 нод** (было пусто). Написаны вручную, по одной фразе.
  ⚠️ `description` **НЕ входит** в снапшот контрактов (там только api, category,
  class_name, display_name, python_file, widgets) — правки описаний снапшот не
  ломают. А вот `category` в снапшоте есть.
- **Встроенная справка** `js/docs/<node_id>/{en,ru}.md` — по две страницы на ноду; список берётся из README, число не зашито (на 18.08.2026 — 60 нод, студия исключена).
  ComfyUI рисует её прямо в ноде (конвенция: `WEB_DIRECTORY/docs/<ключ из
  NODE_CLASS_MAPPINGS>/<locale>.md`, см. docs.comfy.org/custom-nodes/help_page).
  Проверено живьём: 200 на en, ru и на id с пробелами (`TS Files Downloader`).
- **Русские описания** для всех 61 в `locales/ru/nodeDefs.json` (ключ
  `description` рядом с `inputs`/`outputs`). ComfyUI подхватывает через
  `/api/i18n` (`app/custom_node_manager.py`).
- **`example_workflows/`** — 7 шаблонов + jpg. Видны в родном браузере шаблонов:
  `/api/workflow_templates` отдаёт категорию `comfyui-timesaver` со всеми семью.

## Инструменты (dev-only, в git не едут)

- `tools/build_node_docs.py` — генерит справку из README.md/README.ru.md
  (секции `#### <display_name>`). Есть `--check` для CI/проверки расхождений.
  Матчер учитывает составные заголовки («TS Remove Background (BiRefNet)»,
  «A / B»). Скриншоты из секций выбрасываются: они лежат вне WEB_DIRECTORY.
- `tools/build_example_workflows.py` — собирает графы в живом ComfyUI через
  LiteGraph и сохраняет `app.graph.serialize()`. Руками JSON не писать — формат
  дрейфует. Ключевые уроки:
  - раскладка в ДВА прохода: DOM-виджеты (библиотека стилей) досчитывают свой
    размер асинхронно, одного прохода мало — ноды наезжают;
  - страница перезагружается перед каждым шаблоном: DOM-виджет LoadImage
    переживает `graph.clear()` и попадает в чужой скриншот;
  - `--thumbnails` только при английском UI: язык интерфейса — серверная
    настройка пользователя (`Comfy.Locale`), скриптом её не переключаем;
  - **не использовать `PrimitiveString`** — текущий фронтенд рисует его как
    «Text String (DEPRECATED)»;
  - **не ставить `TS_PromptBuilder` в публичные превью** — он показывает имена
    блоков из `nodes/prompts/` (там есть взрослые названия).

в меню, `category` заморожена в CLAUDE.md).
