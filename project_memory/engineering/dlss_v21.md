## Текущая переносимая установка — 2026-11-02

По уточнению владельца используются только относительные пути внутри установленного пака. Пустое v21_directory означает runtime/visual-enhancer/v21; ../ наружу и абсолютные пути запрещены. Официальное приложение перенесено из временного cache в установленный пак, не распространяется через Git. Простые шаги ручной установки находятся в tooltip engine; каноническая инструкция — [runtime guide](../../runtime/visual-enhancer/README.md). Старые абсолютные cache-пути ниже описывают первоначальные прогоны, не нынешнее размещение.

Дословные уточнения владельца, 2026-11-02:

> Абсолютные пути тоже сохраню. - Не, не надо, будет только именно пути соотносительные.

> Инструкция для ручной установки должна быть в Tooltipsi, в том поле, где выбирается движок, максимально простая.

Перенос в установленный пак сверил 1229 файлов, 1 405 218 667 байт по SHA256. Пустой и явный относительный путь проверены из другого cwd; CLI devices видит GPU. 146 связанных тестов, Ruff/compileall и snapshot88 прошли. Код синхронизирован, но ComfyUI не перезапускался, commit/push не выполнялись; для новой схемы/tooltip нужен ручной рестарт. В README восстановлена исходная краткая атрибуция NVIDIA, которую ожидает существующий DLSS-тест после сокращения документации.

## 02.11.2026 — v21 как дополнительный внешний backend

По просьбе владельца добавлен выбор в ТОЙ ЖЕ ноде: `engine` =
`v9 (built-in)` по умолчанию / `v21 (external CLI)`, плюс `v21_directory`.
Оба optional-входа добавлены в конец схемы/сигнатуры; старые графы остаются v9.
Новый `_external_v21.py` запускает целое официальное приложение v21.0 отдельным
процессом. Его файлы не входят в пак и не скачиваются нодой. Проверяются SHA256
CLI и двух DLSSNR DLL конкретной проверенной сборки; нужны все зависимости
приложения. Тестовая установка сейчас в `tests/.cache/upscale-comparison-20261102/upstream/v21`.

Resize перед NR, как у v9; пресет включает только neural_model, factor 1.
Статичные/независимые кадры идут через PNG16; temporal-батч одним FFV1-видео
с внутренним carrier 24fps, без frame generation. Точность выхода видео
определяется приложением, не обещать истинные 16 бит видеотракта. Число кадров и
размеры валидируются, оригинальная альфа переносится отдельно (CLI возвращает
свою непрозрачную RGBA16). У видео CLI НЕ поддерживает `--bit-depth`!
v9-only color/tone/face/grain требуют дефолтов, tone/structure/skin 0..1;
shimmer определяется v21, что явно сообщается в логе/справке.
Отмена завершает только собственный CLI process tree; временные файлы ComfyUI
чистятся через TemporaryDirectory.

Реальные GPU-прогоны: пользовательский PNG 1328x800 -> 2656x1600 дважды,
3.746/3.587 с всего execute; 3 RGBA кадра 320x192 temporal on/off — 3.525/2.521 с,
число/альфа сохранены. Длинные ролики в этой проверке не прогонялись.
145 связанных тестов passed; полный suite не запускался. Generation_seconds=0
в receipt dlss_v21_node — ограничение старого измерителя v9, НЕ нулевое время
новой сети. Не цитировать эту цифру. Версия 12.13.5, без commit/push; изменения
копируются в установленный пак, сервер не перезапускать без новой команды.

Tooltips EN/RU дополнены явной принадлежностью движкам для всех 21 входа:
v9 + v21 / только v9 / только v21 / не используется в обоих. У четырёх
v9-only controls отмечены обязательные дефолты для v21 и ошибка при отклонении;
у shimmer — игнорирование в v21, у tone/structure/skin — отдельные диапазоны.
Исправлено обещание «skin=0 оставляет кожу как есть»: это только дополнительная
фактура, а не блокировка лица. 125 связанных тестов passed, lint/compile OK;
два файла подсказок синхронизированы, сервер не перезапускался.
