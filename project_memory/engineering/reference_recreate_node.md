# «Пересоздать ноду» (01.10.2026)

Просьба владельца: пункт в меню правой кнопки, сбрасывающий ноду на умолчания,
ВКЛЮЧАЯ название, без отключения входов и выходов. Расширение холста, не нода
(как [reference_tidy_layout](reference_tidy_layout.md)): `js/utils/ts-recreate-node.js` + чистая часть
`js/utils/_recreate_node.js`. Крючок `getNodeMenuItems`, команда
`TS.RecreateNode`, id расширения `ts.recreateNode`.

## Как устроено (замерено на фронтенде 1.53.6)

* Снимок связей → `graph.remove(old)` → `LiteGraph.createNode(type)`,
  `fresh.id = old.id` → `graph.add(fresh)`. **Номер сохраняется**: add не
  переназначает id, если он свободен (проверено).
* `node.connect(slot, target, targetSlot, afterRerouteId)` — 4-й аргумент
  уходит в `connectSlots` и становится `link.parentId`: так **точка на проводе**
  (`graph.reroutes`) остаётся на нём.
* Autogrow (`images.image_N` у TextEncodeQwenImage21): следующее гнездо
  появляется только после подключения предыдущего → входы подключать по
  возрастанию номера слота.
* Подбор гнезда: имя → тот же номер и тот же тип (переименование) → нет.
* Не сошлось хоть что-то → новая нода удаляется, старая восстанавливается
  `configure(saved)` с обнулёнными link/links, тот же id, провода по точным
  номерам слотов. Провод не теряется ни при каком исходе.
* `mode` (байпас/выкл.) СОХРАНЯЕТСЯ — состояние графа, не настройка ноды.
  Название, цвет, размер, свойства, виджеты — по умолчанию.
* Ctrl+Z: обёртка `canvas.emitBeforeChange()/emitAfterChange()` —
  `changeTracker.undo()` возвращает прежнюю ноду, `redo()` снова новую.
* Выделение: клик по ноде из выделения пересоздаёт всё выделение
  («Пересоздать ноды: N»). Сабграфы и незарегистрированные типы — без пункта.
* DOM-интерфейсы нод пака (TS LoRA Loader) не оставляют висящих копий.

Тест: `tests/test_recreate_node.py` (17; сценарий `recreated` в
`_SHARED_SCENARIOS`), оба режима нод, настоящий правый клик.
