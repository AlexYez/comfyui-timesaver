Распаковка сабграфа падает от ОДНОЙ мёртвой ссылки в outputs; и даже успешная теряет значения повышенных виджетов

**Граница записи:** ниже сохранены исходные наблюдения и причины решений. Замеры, версии окружения и слова «сейчас» относятся к дате соответствующего наблюдения; это не повторная проверка на новом окружении. Порядок чтения и ограничения: [инженерная память](README.md#как-читать-записи).

# Почему «Unpack Subgraph» ломается на полпути

Жалоба владельца 17.09.2026: в новом графе один сабграф не распаковывается —
«он ломается». Файл: `C:\Users\Sanchez\Desktop\Lipsync LTX.json`, сабграф
«Upscale and re-sampler (3 steps)» (12 узлов, 13 входов, 2 выхода).

## Причина — ровно одна мёртвая ссылка

У экземпляра сабграфа в `outputs[1].links` (`audio_latent`) остался номер связи
**13735**, которой в графе больше нет. Во всём файле это была ЕДИНСТВЕННАЯ
битая ссылка.

Код фронтенда (`LGraph._unpackSubgraphImpl`, бандл `settingStore-*.js`):

```js
if (t.target_id === $s) {                       // связь идёт на выход сабграфа
  for (let n of e.outputs[t.target_slot].links ?? []) {
    let e = this.links[n];                      // ← undefined для мёртвого номера
    d.push({ ..., tid: e.target_id, ... })      // ← TypeError
```

Отсюда `TypeError: Cannot read properties of undefined (reading 'target_id')`.
Падает он ПОСЛЕ того, как узлы уже созданы, и до удаления самого сабграфа —
поэтому в графе оказывается и распакованная копия, и исходный сабграф.

**Проверено перебором** (живой ComfyUI + Playwright, команда
`Comfy.Graph.UnpackSubgraph`):

| что убрали | результат |
| --- | --- |
| повышенный виджет без связи (`RandomNoise.noise_seed`) | падает так же |
| два входа определения, которых нет у экземпляра | падает так же |
| все `reroutes` внутри сабграфа | падает так же |
| **мёртвую ссылку 13735 из `outputs`** | **распаковалось: 41 → 52 узла, `stillSubgraph: 0`** |

## ⚠️ Даже успешная распаковка теряет значения с «лица» сабграфа

Повышенные в интерфейс виджеты, не подключённые снаружи проводом, дают
`console.error("Missing Link ID when unpacking")` и `continue` — связь
выбрасывается, а внутренний узел остаётся со СВОИМ старым значением. На этом
файле: `sampler_name` на лице `euler`, внутри `euler_ancestral`; `noise_seed`
на лице 42, внутри 1234567. После родной распаковки виджеты надо сверять
руками.

## Свой распаковщик

`scratchpad/unpack_subgraph.py` (этой сессии): разбирает сабграф в узлы,
переносит значения повышенных виджетов ПРАВИЛЬНО и обводит блок группой, чтобы
его можно было гасить TS Group Bypasser'ом.

⚠️ Группу нельзя класть на место сабграфа вслепую: рамка захватывает узлы
ГЕОМЕТРИЕЙ, и на этом графе она накрыла бы `VAEDecodeTiled` — байпас группы
убил бы декодер. Скрипт проверяет пересечение и сносит блок ниже графа.

Проверка результата — загрузкой в живой ComfyUI через Playwright
(`app.loadGraphData`, затем `graph.groups[].recomputeInsideNodes()`): 52 узла,
ни одного отсутствующего типа, ни одной висящей связи, в группе ровно 12 узлов.
