Смещение правок Qwen Image 2.1 в «Image Gen Edit Qwen 2» (жалоба пользователя 15.10.2026) — две причины, замеры, и почему лечит только TS Edit Align

Исходники темы: [ts_edit_align.py](../../nodes/image/ts_edit_align.py).

**Граница записи:** ниже сохранены исходные наблюдения и причины решений. Замеры, версии окружения и слова «сейчас» относятся к дате соответствующего наблюдения; это не повторная проверка на новом окружении. Порядок чтения и ограничения: [инженерная память](README.md#как-читать-записи).

Жалоба: в «Image Gen Edit Qwen 2» реставрация/удаление даёт картинку, сильно
смещённую относительно исходника; в Smart Inpaint такого нет (он вклеивает
по маске).

**Причина 1 — провода.** `TextEncodeQwenImage21` (ядро, comfy_extras/
nodes_qwen.py) ужимает референс до `resolution`² (1024) с округлением сторон
к 32 и отдаёт выход `latent` ровно его размера; в подсказке ядра: «any other
size shifts the edit». В графе латент шёл от `TS_ResolutionSelector` (1.5 Мп,
своя формула) — размеры не совпадают.

**Причина 2 — сама модель.** Даже с латентом от энкодера Qwen 2.1 оставляет
ошибку: вертикальный 1100×1980 — масштаб 0.3% и сдвиг 2.7 px (6 px у края).

Замеры (плитки + фазовая корреляция, затем пиксельная ошибка в текстурных
местах вне правки): как в графе 960×720 — 2.8 px и 0.5% (5 px у края),
1100×1980 — 7 px. После TS Edit Align ошибка −66…−68% (и −8/−32% поверх
правильного латента), остаток ~5–7 ед. — перерисовка деталей, не сдвиг.

**TS Edit Align** (`TS_EditAlign`, `nodes/image/ts_edit_align.py`,
TS/Image/Retouch): правка → точный размер исходника (обратимо: растяжение по
осям аффинно) → сетка плиток, фазовая корреляция с субпиксельным пиком →
робастная подгонка сдвиг+масштаб по осям (правленые плитки выпадают как
выбросы) → один bicubic grid_sample; два прохода. Мало текстуры → не двигает.
Без `source` — проходит насквозь (граф продолжает работать как t2i).
⚠️ Параболический субпиксельный пик ЗАНИЖАЕТ сдвиги ~0.5 px — для ОЦЕНКИ
результата брать пиксельную ошибку, а не тот же замер (на этом спотыкался).

**`output_size`** (добавлен 15.10.2026 по просьбе владельца: «а если хочу
увеличить?»): `source` — размер оригинала (по умолч.); `edit` — размер, в
котором рендерила модель, а для замера растягивается ОРИГИНАЛ. Замер на той
же правке: 1408×1056 сохранён, найден тот же дрейф (4.16 px в пикселях правки
= 2.82 в пикселях исходника, −0.54%), ошибка 22.6 → 7.4, мелкой детали на 14%
больше, чем при ужатии до 960×720 и обратном растяжении. `edit` — перед
апскейлером; `source` — когда правку смешивают с оригиналом.
Граф владельца: «Image Gen Edit Qwen 2 - Edit Align» (оригинал не тронут).
