Реальные баги и минимальные исправления:
1. RT finish_answer пропускал Json Image Capture, обрабатывая только
   XYXY_PRESETS. Теперь берёт оба JSON_PRESETS; xyxy=True ТОЛЬКО для
   Ideogram Prompt Enhance. Capture y-first не транспонируется.
2. Перевод сплющивал уже английские строки. Если answer.split()==idea.split(),
   RT возвращает исходное форматирование. Язык не угадывается, слова настоящего
   перевода не меняются. "now here" и "nowhere" не считаются одинаковыми.
3. Из временных имён сохранённых workflow идут правильные скрытые алиасы,
   а не fallback общего пресета.
