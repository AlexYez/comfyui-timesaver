Как собирать большие workflow из встроенных шаблонов ComfyUI только родными нодами — общий размер на API-ноды через CustomCombo→GetItemFromList, StringFormat, RegexReplace; входы сабграфов; ловушки проверки

**Граница записи:** ниже сохранены исходные наблюдения и причины решений. Замеры, версии окружения и слова «сейчас» относятся к дате соответствующего наблюдения; это не повторная проверка на новом окружении. Порядок чтения и ограничения: [инженерная память](README.md#как-читать-записи).

Опыт сборки «T2I Models Compare» (04.10.2026, 22 локальные модели + 19 API, всё родное).
Сборщик лежал в scratchpad (`build_t2i_compare.py`) — идеи ниже, кода в репо нет.

- **Строку в выпадающий список родными нодами не подать**: `STRING → COMBO` бэкенд
  отвергает (`validate_node_input`). Но `*` (AnyType) проходит, а у ПРИВЯЗАННОГО combo
  значение по списку не проверяется. Цепочка: `CustomCombo`(варианты задаются на ноде,
  `widgets_values=[choice, index, opt1..optN, ""]`) → `STRING` → `GetItemFromList`
  (index 0, `is_input_list` заворачивает одиночное значение в список) → `*` → любой combo.
- **`StringFormat`** (`values.a..` + `f_string`) собирает строки каталогов вида
  `"(2K) {a}x{b} ({c})"`, `"{a}x{b}"`; числа — `ComfyMathExpression` с тернарником
  `X if a==0 else Y if a==1 ...` (simpleeval; есть min/max/round/sqrt). **`RegexReplace`**
  подменяет соотношение для нод без него (21:9 → 16:9).
- Индекс `CustomCombo.INDEX` — с нуля. Сверять все порождаемые строки со списком
  опций каждой целевой ноды прямо в сборщике — расхождение = ошибка API при запуске.
- **Вход сабграфа снаружи** сопоставляется ПО ИМЕНИ: у внешней ноды список `inputs`
  неполный, достаточно дописать `{name, type, widget:{name}, link}`. Значение, видимое
  только как `proxyWidgets` (`["8","seed"]`), проводом не подключить — добавить вход в
  определение: запись в `sub.inputs` + связь `origin_id:-10` к внутренней ноде, а proxy
  заменить на `["-1", name]`.
- У шаблонов два стиля значений сабграфа: позиционный `widgets_values` внешней ноды по
  порядку входов определения ИЛИ пустой список + значения во внутренних нодах.
- ⚠️ Проверка перед запуском обходит ВСЕ привязанные ноды, даже за выключенной веткой
  `ComfySwitchNode` → `LoadImage` с отсутствующей картинкой валит весь граф. Ветки с
  референсами из шаблонов (HiDream O1, Nano Banana Pro, Kling O3) вырезать.
- Провод во вложенное поле DynamicCombo (`model.prompt`) на фронтенде 1.53.6 рвётся,
  только если сохранённый вариант ≠ варианту по умолчанию (см. [reference_sliders](reference_sliders.md)
  рядом — та же ошибка FE-258); у большинства API-нод модель одна — провода живут.
- Для Comfy Cloud имена моделей оставлять шаблонными (без локальных подпапок).
- Владелец: **int8 приоритетнее fp8** (новый формат). Замена — только на имена, которые
  есть в каком-нибудь шаблоне (значит, лежат в облаке); вместе с именем менять и запись
  `properties.models` (url). Сэмплеры — только родные: `res_2s`, `bong_tangent`, `beta57`
  в локальных списках — это инжекторы НАШЕГО пака, в облаке их нет.
- «Идеальное разрешение» модели = её родной бюджет пикселей при общем соотношении сторон:
  своя пара `ComfyMathExpression` в группе модели. Qwen-Image: 1,4727 Мп кратно 32 даёт
  ровно официальный 16:9 = 1664×928; SDXL 1 Мп кратно 64 = бакет 1344×768.
- Негатив работает только при CFG > 1 (`BasicGuider` и CFG 1 его игнорируют). Подобранный
  в шаблоне негатив не затирать — `StringConcatenate` «свой + общий»; из общего негатива
  убирать голое «text» (ломает надписи) и стилевые слова (аниме-модели в наборе).
- **Длина промпта в ComfyUI 0.38 (по коду):** CLIP-L/G — куски по 77 токенов, не обрезает, а
  склеивает (хвост не теряется, а мешает); T5 и энкодеры-LLM — без предела в токенизаторе
  (`max_length=99999999`). Реальные пределы: **PixelDiT ~300 токенов Gemma** (`pixeldit.py`,
  `_PIXELDIT_MAX_LENGTH`, хвост отрезается), **LongCat 512 токенов** (`longcat_image.py`, текст в
  кавычках токенизируется ПО СИМВОЛУ). API (в символах, нода падает ДО запроса): Kling 3.0
  (`KlingImageGenerationNode`) — 500, Runway t2i — 1000 (pydantic), Kling O3 — 2500, Recraft V4 и
  Ideogram 4.5 — 10000, Flux 3 — 15000, MAI (OpenRouter) — 20000. ⚠️ «1024» у
  `TextEncodeQwenImage21` — разрешение референсов, НЕ длина текста.
- Тип CLIP `ideogram4` грузит полный Qwen3-VL-8B с генерацией (`sd.py`, комментарий
  «multimodal generate») — его можно звать `TextGenerate` для JSON-описания Ideogram v4.
