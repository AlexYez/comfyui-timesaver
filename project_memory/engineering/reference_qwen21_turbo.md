**Граница записи:** ниже сохранены исходные наблюдения и причины решений. Замеры, версии окружения и слова «сейчас» относятся к дате соответствующего наблюдения; это не повторная проверка на новом окружении. Порядок чтения и ограничения: [инженерная память](README.md#как-читать-записи).

# Турбо-LoRA Qwen Image 2.1: TS Shifted Sigmas + TS LoRA Unmerged

Сделаны 28.09.2026 взамен двух нод Viggle (`viggle_turbo.py` из
`huggingface.co/Viggle/Qwen-Image-2.1-viggle-turbo/tree/main/comfyui`). Код свой,
не копия: у Viggle один файл без лицензии на код.

## Сверено на живой модели (не на словах)

Скрипт гонял настоящую `qwen_image_2.1_int8_convrot` + LoRA
`Qwen-Image-2.1-viggle-turbo-v0.2.1-6step-lora-r128` на RTX 3080 Ti Laptop,
1024×1024, один вход на все варианты:

- сигмы: 28 случаев (7 размеров × латент /8 и /16 × 5 и 6 шагов) — разница с
  Viggle **0.0**; в тестах ещё и против `FlowMatchEulerDiscreteScheduler` из
  diffusers 0.36. 1024²: 1.0, 0.96775, 0.93336, 0.85719, 0.66676, 0.40010, 0.
- LoRA: выход модели **побитно** равен ноде Viggle; детерминирован.
- время шага: 2.9 с без LoRA, 3.45 с с веткой (у Viggle столько же).
- штатное слияние (`load_lora_for_models`) на int8 уходит от точного результата
  на 0.49 всего действия LoRA (действие LoRA = 22% нормы выхода).

## Грабли

- ⚠️ **MLP у Qwen 2.1 слитый**: `gate_layer`+`proj` = один `gate_up`, LoRA
  адресует половинки. Какая куда — брать из `comfy.lora.model_lora_keys_unet`
  (кортеж `(key, (0, offset, size))`), не угадывать.
- ⚠️ **`out` под int8 мимо своих хуков**: `comfy.ops.linear_input_act` сворачивает
  SwiGLU в квантователь входа и зовёт GEMM напрямую. Ветку `out` вешать на весь
  MLP, считая `silu(gate)*up` из выхода `gate_up` (с поправками). Под bf16 хуки
  `out` сработали бы — но тогда ветка посчиталась бы дважды, поэтому MLP-путь
  всегда.
- ⚠️ Выход `gate_up` пишут ВСЕ наши хуки на нём (общий слот `_GATE_UP`): при двух
  LoRA подряд последняя запись несёт поправки обеих. Тест
  `test_two_loras_in_a_row_add_up`.
- ⚠️⚠️ Слот — ОДИН на поток, не словарь по модулям. Первая версия держала
  `WeakKeyDictionary` модуль → выход и чистила его только в `finally`: к концу
  прохода там лежали выходы ВСЕХ 32 блоков, ~6 ГБ VRAM на 1024² (найдено
  аудитом 29.09.2026). MLP блока проходит целиком до следующего, поэтому слота
  хватает; `threading.local` — ради multi-GPU. Сторож
  `test_only_the_current_block_gate_up_is_held`.
- ⚠️⚠️ **ComfyUI 0.38+ (30.09.2026): тензор не должен переживать свой блок.**
  `comfy/model_prefetch.py` пишет схему выделений comfy_aimdo по блокам
  (`malloc_graph.iterate("block")`), блоки ПРЕФИКСА шага 1 идут внутри
  `pause_malloc_graph()`. Слот, державший выход прошлого блока, освобождался в
  паузе → `RuntimeError("aimdo memory compile error")` на `resume`
  (воспроизведено на живом 0.38.0, qwen_image21/model.py:380). Лечение: слот
  считает читателей (`add_readers`/`consumed`), последний читатель очищает его
  в хуке MLP; без читателя запись не делается (`wanted`). Сторож
  `test_the_gate_up_output_does_not_outlive_its_own_mlp`. Общее правило для
  хуков на 0.38: ничего, выделенное внутри блока, не держать за его пределами.
  Нода Viggle (словарь выходов всех блоков) на 0.38, по-видимому, падает так же.
- ⚠️ Тип ветки — из `x` (ядро уже привело его к `get_dtype_inference()`), НЕ из
  `diffusion_model.dtype`: у fp8-модели там float8, и A/B в fp8 теряли 28-67%
  (замер). `branch_dtype()` пропускает только fp16/bf16/fp32.
- Веса на устройство кладёт обёртка `OUTER_SAMPLE` ДО загрузки модели, после
  `free_memory(nbytes)` — так их видит менеджер памяти. Кэш весов — словарь
  по (устройство, тип) под замком.
- DoRA отклоняется ошибкой; кортежи карты ключей не вида `(key, (0, off, size))`
  (у Flux/SD3 бывает `(key, None, swap)`) уходят в «не сопоставлено»; метаданные
  PEFT берутся только от `transformer.`/`unet.`/без префикса.
- Хуки ставятся на один вызов в обёртке `DIFFUSION_MODEL` и снимаются в `finally`
  — диффузионная модель общая для всех клонов патчера.
- Веса LoRA на устройстве живут одну выборку (обёртка `OUTER_SAMPLE` их
  отпускает); ComfyUI их при планировании памяти не видит (~0.7 ГБ у r128).
- Счёт токенов — как в ядре: пустой латент с `downscale_ratio_spacial` сэмплер
  пересчитывает на /16 (`fix_empty_latent_channels`), латент с содержимым — нет.
  Viggle делит на метку всегда; расходится только на непустом латенте с меткой /8,
  которого штатные ноды не дают.
- У модели есть prefix K/V cache (`current_patcher` → `reset_prefix_cache`); в
  своих прогонах вне сэмплера ставить `model.current_patcher = None`, иначе кэш
  из прошлого прогона.
