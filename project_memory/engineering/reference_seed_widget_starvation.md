# ⚠️ Незаявленный `control_after_generate` съедает значение последнего виджета

**Найдено 2026-07-25 (v9.86)** живым аудитом всех 61 ноды.

## Симптом

`TS_Qwen3_VL_V3.video_max_frames` **всегда** возвращался к дефолту `16` после
перезагрузки workflow — какое бы значение пользователь ни выставил. Значение
корректно попадало в `widgets_values` при сохранении, но не применялось при
загрузке.

## Механизм (доказан инструментацией сеттера)

Фронтенд ComfyUI рисует виджет `control_after_generate` рядом с любым виджетом
по имени `seed`/`noise_seed` — **даже если схема его не объявляет**. Тогда:

- `node.widgets` = 15 (14 виджет-входов схемы + служебный control),
- загрузчик применяет позиционно ровно **столько значений, сколько
  виджет-входов в определении ноды** (14),
- значения ложатся на `widgets[0..13]` корректно, а `widgets[14]` — последний
  реальный виджет — **не получает ничего** и остаётся с дефолтом.

Сеттер последнего виджета при загрузке не вызывается ни разу (проверено через
`Object.defineProperty`). Подтверждающий эксперимент: если выровнять длины
(убрать служебный виджет и из сохранения, и из списка при загрузке), значение
применяется — `video_max_frames = 44` ✔.

## Решение

Объявлять `control_after_generate=True` у **каждого** `seed`-входа — тогда
определение ноды и отрисованный список виджетов совпадают. Так делают родной
`KSampler` и наш `TS_PromptBuilder` (обе иммунны). Исправлены: `ts_qwen3_vl.py`,
`ts_film_grain.py`, `ts_smart_inpaint.py`.

**Требует перезапуска ComfyUI** — правка в Python-схеме. **Проверено после
рестарта 2026-07-25:** `video_max_frames` сохраняется при 20/44/128 ✔,
`/object_info` отдаёт `control_after_generate: true`, полный сьют 783 passed.

Побочно исправлен `tests/test_voice_recognition_audio.py`: он патчил
`_voice._load_whisper_runtime` (re-export), а реальный `import whisper` живёт в
`nodes/_whisper_engine.py::load_runtime`. Из-за этого тест тянул numba и падал
на NumPy 2.5. Теперь патчится движок (место определения) — сьют зелёный целиком,
известный «окруженческий» фейл был на самом деле дефектом теста.

## Правила

- Новый `seed`/`noise_seed` вход — ВСЕГДА с `control_after_generate=True`.
- Гард: `tests/test_seed_control_after_generate.py` (статический, AST, без
  ComfyUI) — не даст добавить seed без флага.
- Общий гард на потерю значений: `tests/test_all_nodes_roundtrip.py` — гоняет
  все 61 ноду через «выставить каждый параметр → сохранить → перезагрузить →
  собрать промпт» и требует побайтового совпадения.
- Это **баг ядра ComfyUI**, не только наш: родная `ElevenLabsSpeechToSpeech`
  теряет последний виджет ровно так же.
