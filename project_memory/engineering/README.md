## Как читать записи

1. Сначала прочитайте актуальное вступление темы и связанный исходник. Датированные наблюдения сохраняют контекст старой ошибки и объясняют причину решения; они не превращаются в актуальную спецификацию лишь из-за даты консолидации.
2. Вступления сверены там, где явно названа текущая опора; сохранённые аппаратные замеры, состояния чужих сервисов и локальные эксперименты заново не проводились. Старые «сейчас», «осталось», числа тестов и пути относятся к дате соответствующей записи.
3. `tests/`, `tools/`, `archive/`, `dist/`, внешние рабочие проекты и файлы ComfyUI могут встречаться как исторические источники. Это локальная лаборатория владельца, не обещание наличия в чистом клоне. Снимок `tests/contracts/node_contracts.json` является отслеживаемым исключением. Снятый код восстанавливают по Git history, не по обязательному локальному ZIP.
4. Абсолютные Windows-пути — примеры установки владельца. Переносимое описание находится в [окружении](../../doc/operations/environment.md). Не воссоздавайте чужой путь и не запускайте процесс только потому, что он упомянут в памяти.
5. Команды проверки и релиза берите из [operations](../../doc/operations/README.md). История тестов не разрешает запуск полного suite; описание старого рестарта не разрешает останавливать рабочий сервер.

## Границы актуальности

Последняя консолидация: 2026-11-02, после релиза 12.13.6. Миграция меняет только документацию. При противоречии наблюдения с исходным кодом текущий интерфейс определяет код, а цитату требования владельца сохраняют как исходное решение с датой.
