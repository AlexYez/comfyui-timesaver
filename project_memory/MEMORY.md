Память проекта хранится в репозитории и открывается по теме задачи, а не целиком.

| Раздел | Что искать |
|---|---|
| [Требования владельца](owner/README.md) | Дословные поправки, запреты, совместимость, проверки, push, версия и lifecycle ComfyUI. |
| [Продуктовые решения](decisions/README.md) | Назначение проекта, выбранные подходы и причины; политика хранения знаний. |
| [Инженерная память](engineering/README.md) | Загрузчик, frontend, media, модели, промпты, проверки и ловушки подсистем. |
| [История](history/README.md) | Снятые функции, прежние эксперименты, аудиты и результаты релизов. |

Каждая тема индексируется одной строкой в своём hub; большие темы имеют собственное оглавление и части. Выберите раздел, затем только нужную запись.

**Приоритет:** прямое указание владельца → более поздняя датированная дословная поправка → текущий код для технических фактов → пересказ в памяти. Историческое разрешение не отменяет явно более поздний запрет. Если код не разрешает противоречие требований, сохраните обе версии и обозначьте вопрос.

Для входа в работу используйте [AGENTS.md](../AGENTS.md); актуальные команды и структура — в [документации](../doc/README.md). Версия берётся из [pyproject.toml](../pyproject.toml), публичные схемы — из [контрактов](../tests/contracts/node_contracts.json). Старая запись памяти сама по себе не является доказательством текущего поведения модели.

Новые знания сохраняйте в подходящем разделе с frontmatter, кратким резюме, причиной решения, абсолютной датой и ссылкой на код/источник. Переносы и проверка полноты этой структуры описаны в [отчёте консолидации](../doc/maintenance/CONSOLIDATION.md).
