Два существующих пресета связывают идею или изображение с JSON-описанием Ideogram; имена и смысл сохраняются.

# Пресеты JSON для Ideogram

Два существующих ключа в [общем файле пресетов](../../nodes/qwen_3_vl_presets.json) решают разные задачи:

- `Ideogram Prompt Enhance` — улучшить идею и/или использовать изображение, сохраняя явные требования пользователя.
- `Json Image Capture` — описать видимое изображение, не выдумывая скрытых деталей и сохраняя видимые надписи в исходном языке.

Разделение по смыслу важно: творческое дополнение идеи нельзя незаметно включать в точное восстановление картинки. Новые копии с именем модели не нужны: действует [требование обновлять существующие пресеты](../owner/feedback_update_existing_llm_presets.md).

Формат и преобразование координат описаны в [инженерной памяти](../engineering/ideogram4-caption-format.md), поведение десигнера — [его тема](../engineering/ts-ideogram-designer-node.md). Данные пресетов — канонический источник инструкций и sampling-параметров; не копировать их целиком в память.

По сверке 2026-11-02 старые числа temp 0.45/0.3 и top_p 0.9/0.85 устарели. Текущий файл задавал Enhance 0.2/0.85 и Capture 0.15/0.8; длины системных инструкций — 4090 и 2258 символов. Это снимок проверки, не отдельные значения по умолчанию: следующие правки должны читать сам JSON.

Исторические проверки компактных примеров на ассистентах не были измерением реальных Qwen 2B/4B. Следовательно, они подтверждали читаемость инструкции, но не качество вывода небольшой модели; для изменения качества нужны реальные ответы на фиксированных заданиях. Одноразовый `build_ideogram_presets.py` находился в скретчпаде и не является обязательной утилитой проекта.
