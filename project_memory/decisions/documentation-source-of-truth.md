Репозиторий должен быть достаточным источником для пользователя и ассистента, без скрытых знаний в приватной памяти отдельной машины.

## Требование владельца, 2026-11-02

> Everything the project needs lives inside the repository: persistent memory (for example a `project_memory/` folder with an index), documentation, decisions and their reasons.

> My corrections and preferences stay in my own words — they outrank any summary.

> This is documentation and memory work only: leave code and behaviour unchanged.

Это явно заменяет прежнее требование исключать project_memory и инструкции ассистентов из Git. Его исходные формулировки сохранены с отметкой истории в [правиле расположения](../owner/feedback_runtime_only_locations.md). Тесты/инструменты локальной лаборатории, модели, кэши и секреты этой задачей не публикуются.

## Почему так

Большие монолитные README, CLAUDE и индекс памяти вынуждали загружать слишком много контекста, при этом новый Git-клон не содержал большей части правил. Разделение оставляет короткий вход, тематические оглавления и один канонический источник каждого текущего факта. Исторические наблюдения сохраняются с датой, а не выглядят активной инструкцией.

Новые документы должны быть небольшими; ориентир — до 25 КБ UTF-8. Внешняя память ассистента может хранить только короткий указатель на этот репозиторий. Публичные файлы не содержат токенов или личных runtime-данных.

Порядок обслуживания и проверенные переносы — [консолидация](../../doc/maintenance/CONSOLIDATION.md).
