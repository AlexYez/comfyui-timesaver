# Назначение продукта

`comfyui-timesaver` — набор ComfyUI custom nodes и frontend extensions для экономии времени в рабочих графах изображений, видео, аудио, текста и LLM. Ноды предназначены и для опытных пользователей, и для новичков; объяснения параметров и встроенная справка являются частью продукта.

Код и публичный интерфейс важнее старых подсчётов памяти. Актуальные версия и требования находятся в [pyproject.toml](../../pyproject.toml), идентификаторы и порядок входов — в [снимке контрактов](../../tests/contracts/node_contracts.json), справка — в [каталоге нод](../../doc/nodes/README.md). Не дублировать эти меняющиеся значения в каждом документе.

На сверке 2026-11-02 снимок содержал 88 node_id, все с api=v3; в `js/docs/` было 88 пар en/ru. Старое описание «версия 12.1.0, 73 ноды, 11 студийных и 62 справки» относилось к снятой TS Image Studio и не описывает текущий пак. Текущее состояние и группировка по подсистемам — [архитектура](../../doc/architecture/README.md).

Почему считаем по node_id: число файлов `ts_*.py` включает служебные модули и не равно числу публичных нод. Инжекторы samplers/schedulers и shim совместимости не следует прибавлять к счётчику нод. Почему сохраняем публичные имена и порядок виджетов — [требование совместимости](../owner/feedback_compatibility.md).

Снятые функции описаны в [истории](../history/README.md), а не в текущем справочнике. Поддержка платформ и ограничения отдельных нод следуют из их кода/справки; нельзя переносить Windows-only ограничение DLSS на весь пак.
