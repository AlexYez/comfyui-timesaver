# TS Edit Align

Совмещает отредактированную картинку с исходным холстом. Подходит для реставрации,
удаления объектов и других правок, которые нужно наложить на оригинал или сравнить шторкой.

Подайте результат VAE Decode (или TS VAE Fix, если он есть в графе) в `image`, а
исходный холст в `source`. Нода измеряет сдвиг и масштаб по каждой оси на
согласующихся участках. Строка состояния показывает результат замера.
Выравнивание исправляет геометрию. Цвет и детали остаются результатом работы модели.
Без `source` картинка проходит напрямую, поэтому тот же граф подходит для генерации по тексту.

**`output_size`.** `source` (по умолчанию) возвращает правку в размере исходного
холста для наложения или смешивания. `edit` сохраняет размер генерации и приводит
исходник к нему для замера. `max_shift` задаёт ограничение поиска в пикселях
выходного кадра. Начальное значение — 24.

**MiniMax H3 / P-H3 Image.** Используйте ту же ноду, что и для Qwen Image Edit
или Flux Kontext. Если граф вписывает исходную картинку в выбранный TS Resolution
Selector холст, подключите в `source` тот же подготовленный кадр, который идёт в
`image_1` Conditioning, например выход ResizeAndPadImage. С `output_size=edit`
итоговое разрешение сохраняется. При намеренной смене ракурса или композиции
отключите выравнивание. Полная перерисовка и малое число фактурных участков
снижают надёжность замера.
