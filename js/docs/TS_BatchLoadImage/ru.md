# TS Batch Load Image

Читает одну картинку по пути — пара к TS Batch Source, который раздаёт пути, а не изображения. Отдаёт картинку, её альфу маской и имя файла без расширения (подайте его в TS Batch Write — и подпись ляжет рядом со своей картинкой).

**Когда нужна:** обход папки вместе с TS Batch Source. Для одного файла проще штатные загрузчики.


<a id="video"></a>
### 🎬 Видео (10 нод)

Чтение и запись видеофайлов, интерполяция кадров, апскейл моделью, глубина, превью анимации.
