# TS Prompt Builder

Собирает промпт из файлов wildcard и вашего текста в указанном порядке.
Каждый включённый TXT-блок даёт одну случайную непустую строку, каждый
включённый текстовый блок — ваш текст. Части соединяются через запятую и пробел.

Кнопка **Открыть интерфейс** показывает блоки плитками в общем полноэкранном
редакторе пака. Переставляйте плитки за ручку; с клавиатуры — **Alt + стрелки**,
когда переключатель блока в фокусе. Номер плитки показывает её место в итоговом промпте,
переключатель включает или выключает блок. Закрытие — **Esc** или общий крестик.
Компактная нода и полноэкранный редактор используют одно состояние.

**+ Свой текст** добавляет редактируемый блок. Можно создать несколько таких
блоков, поставить их до, между или после файлов, выключить либо удалить
кнопкой ×. Текст, порядок и включённость сохраняются в workflow, в существующем
`config_json`; новые входы ноды не добавляются. Свой текст не записывается в
общую конфигурацию. Выполнение сохранённого workflow не перезаписывает
настройки по умолчанию для других workflow.

Wildcard-файлы — `.txt` непосредственно в `nodes/prompts/`, один вариант на
непустую строку. Подпапки и семантические карты не читаются. **Обновить** заново
читает список файлов без перезапуска ComfyUI, сохраняя ваш текст и прежний
выбор. Новые файлы в сохранённом workflow добавляются выключенными; удалённые
с диска исчезают из списка. Явные перестановки и переключения файлов также
сохраняются как настройки новых нод. Свой текст всегда остаётся только в workflow.

`seed = 0` выбирает новые случайные строки при каждом запуске. Положительный
seed воспроизводит выбор для каждого файла: перемещение или правка своего
текста не меняет случайную строку другого блока. Переносы строк в своём тексте
сохраняются.
