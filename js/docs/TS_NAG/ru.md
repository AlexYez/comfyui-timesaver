# TS NAG

**Негативный промпт там, где его быть не может** — на дистиллированной модели с `cfg = 1`.

При `cfg = 1` ComfyUI негативную ветку просто не считает: провод есть, смысла нет. NAG (*Normalized Attention Guidance*, [статья](https://github.com/ChenDarYen/Normalized-Attention-Guidance)) заходит с другой стороны — он применяет негатив **внутри каждого блока cross-attention**. С тем же запросом внимание считается дважды, с позитивным контекстом и с негативным, а дальше:

```text
guidance = x_поз · scale − x_нег · (scale − 1)      экстраполяция
r        = ‖guidance‖₁ / ‖x_поз‖₁                   на каждый токен
если r > tau:  guidance ← guidance · (‖x_поз‖₁ · tau / ‖guidance‖₁)
out      = guidance · alpha + x_поз · (1 − alpha)
```

Обрезка по `tau` — то, ради чего в названии «normalized»: экстраполяция с коэффициентом 11 без неё разносит активации. `nag_scale` — сила, `nag_tau` — потолок отклонения, `nag_alpha` — сколько подмешать обратно.

**Цена — одно лишнее cross-attention на блок, а не второй проход модели.** В этом весь смысл: запрос идёт от картинки к короткому тексту, это дёшево.

⚠️ **Работает не со всякой моделью, и это не каприз.** Нужен настоящий отдельный модуль cross-attention, который можно позвать второй раз:

| модель | |
|---|---|
| **Wan** | `blocks[i].cross_attn`, отдельно T2V и I2V — поддержана |
| **LTX** | `transformer_blocks[i].attn2` — поддержана |
| **Krea 2**, **MiniMax H3** | текст и картинка склеены в одну последовательность до всех блоков — **отказ с объяснением** |

У однопоточных моделей негативный вариант пришлось бы тащить через весь стек, а это второй полный проход — ровно то, что делает CFG. Нода честно говорит об этом и отправляет поднять `cfg`, вместо того чтобы делать вид, что сэкономила.

Семейство определяется **по структуре блоков**, а не по имени файла: `model_type` = `auto`. Какие строки батча позитивные, нода спрашивает у ядра (`cond_or_uncond`), а не угадывает по форме — иначе пачка из двух картинок при `cfg = 1` была бы неотличима от пары «позитив + негатив».

> Идея и умолчания — из ноды `WanVideoNAG` [kijai/ComfyUI-KJNodes](https://github.com/kijai/ComfyUI-KJNodes). Для Wan математика повторена один в один, включая место, где сходятся две ветки, — чужие настройки переносятся как есть. Для LTX оригинальный `forward` вызывается дважды, а свёртка идёт после выходной проекции: дублировать внутренности LTX (RoPE, маски-гиды, пер-головное гейтирование) значило бы ломаться при каждом их обновлении.

**Когда использовать:** дистиллированная модель на `cfg = 1`, и нужно от чего-то избавиться — «без текста», «не мультяшно», «без лишних пальцев».
