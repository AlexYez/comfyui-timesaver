# TS Float Slider

Float-аналог для кадров в секунду, мегапикселей, силы эффекта. Новая нода ходит от 0 до 10 с шагом 0.1; диапазон и шаг меняются в свойствах ноды. Значения только неотрицательные, верхний предел — 10 000. Старые ноды с диапазоном −1e9 … +1e9 при открытии получают рабочий диапазон, текущее значение сохраняется.

**Когда использовать пару:** нужен чистый виджет параметра без перетаскивания полноценной math-ноды на граф.
