# TS Shifted Sigmas

**Расписание, на котором дистиллирована турбо-LoRA для Qwen Image 2.1 в несколько шагов**, — писалось под [viggle-turbo](https://huggingface.co/Viggle/Qwen-Image-2.1-viggle-turbo) от Viggle.

Такую LoRA учат на нескольких «сырых» шагах — по умолчанию `1.0, 0.9375, 0.875, 0.75, 0.5, 0.25`, шесть штук. Пайплайн diffusers не берёт эти числа как есть: он изгибает их сдвигом, который растёт вместе с размером картинки:

```text
tokens = (высота / 16) · (ширина / 16)
mu     = 0.5 + (0.9 − 0.5) · (tokens − 256) / (8192 − 256)
sigma  = e^mu / (e^mu + (1/t − 1))            и в конце 0
```

Ни один планировщик ComfyUI такого не выдаёт — они либо раскладывают шаги сами, либо применяют постоянный сдвиг без оглядки на разрешение, — а турбо-LoRA на чужом расписании теряет резкость. Нода отдаёт расписание число в число: сверено с `FlowMatchEulerDiscreteScheduler` из самого diffusers и с нодой Viggle на 28 размерах — разница ноль.

Размер читается из латента **так, как его увидит сэмплер**: пустой латент от штатного *Empty Latent Image* (сетка /8) сэмплер сам переводит на /16 Qwen, поэтому и считается по /16; латент с содержимым — по тому размеру, что у него есть.

Подключать в `SamplerCustom` / `SamplerCustomAdvanced` с сэмплером `euler` и без CFG (`BasicGuider` или `cfg 1`). Добавлять и убирать шаги — **только с шумного конца**, `0.875, 0.75, 0.5, 0.25` оставить: пять шагов — `1.0, 0.875, 0.75, 0.5, 0.25`, семь — `1.0, 0.9583, 0.9167, 0.875, 0.75, 0.5, 0.25`. Список можно вставить прямо из описания модели — дроби вида `1 / 6` и квадратные скобки нода понимает.

**Режим на 9 шагов (viggle-turbo v0.3)** — 7 шагов с турбо-LoRA, последние 2 доводит базовая модель без неё. Собирается штатными нодами: TS Shifted Sigmas с `[1.0, 0.9583, 0.9167, 0.875, 0.75, 0.5, 0.25, 1 / 6, 1 / 12]` → `SplitSigmas` со `step = 7`; верхняя половина — в первый `SamplerCustomAdvanced` с моделью под LoRA и `RandomNoise`, нижняя — во второй, с той же моделью без LoRA и `DisableNoise`, латентом из выхода `output` первого. Стык точный: у euler нет памяти между шагами, а кэш текста и референса у Qwen 2.1 ComfyUI сбрасывает на каждом прогоне сэмплера — вторая половина пересчитает его уже без LoRA, как переключение `kv_cache_mode` у Viggle.

**Когда использовать:** любая LoRA для Qwen Image 2.1 в несколько шагов, дистиллированная на расписании diffusers, — в паре с TS LoRA Unmerged ниже.
