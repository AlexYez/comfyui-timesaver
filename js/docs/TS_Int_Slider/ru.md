# TS Int Slider

Чистый integer-слайдер, возвращающий `INT`: шаги сэмплера, секунды, разрешение. Новая нода ходит от 0 до 2048 с шагом 8; свой диапазон и шаг задаются в свойствах ноды (`min`, `max`, `step`, `default`). Значения только неотрицательные, верхний предел — 100 000.
