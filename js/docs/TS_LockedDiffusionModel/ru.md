# TS Load Diffusion Model

Аналог `UNETLoader`. Те же варианты приведения весов (`fp8_e4m3fn`, `fp8_e5m2` и быстрый режим). Загруженная модель запоминает, как загрузиться снова, — иначе при глубоком клонировании и работе на нескольких картах копия осталась бы без весов.
