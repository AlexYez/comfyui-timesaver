# TS Load CLIP

Аналог сразу четырёх нод: `CLIPLoader`, `DualCLIPLoader`, `TripleCLIPLoader` и `QuadrupleCLIPLoader`. До четырёх файлов в одной ноде, лишние входы оставляют на `none`. Есть `device = cpu`, чтобы энкодер не занимал карту.
