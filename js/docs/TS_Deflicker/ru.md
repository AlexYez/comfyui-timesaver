# TS Deflicker

Сглаживает короткие перепады яркости в упорядоченном батче IMAGE.
Подходит для видео после декодирования и для последовательностей картинок.
Нода оценивает общую поправку по нескольким областям и применяет её к
текущему кадру. Альфа-канал сохраняется. Нейросетевые веса не нужны.

- **segments_info** ограничивает коррекцию стыками TS Latent Upscale и
  несколькими соседними кадрами, на которые может повлиять стык. Без этого
  входа нода ищет короткие скачки в каждой сцене.
- **reference** — синхронный черновик с тем же числом кадров и пропорциями.
  Его разрешение может быть меньше. Нода стабилизирует разницу яркости с
  черновиком, чтобы сохранить задуманное изменение света.
- **strength** задаёт силу коррекции. При нуле кадры проходят как есть.
- **radius** задаёт число соседних кадров с каждой стороны для поиска
  коротких скачков. При подключённых стыках и черновике используются
  границы из segments_info.

В Lipsync H3 подключите VAE Decode после апскейла к images, VAE Decode
черновика к reference и выход segments_info апскейлера к одноимённому
входу. Звук идёт напрямую в сохранение видео. Без черновика короткая
настоящая вспышка может выглядеть как дефект экспозиции. Один кадр
передаётся как есть.
