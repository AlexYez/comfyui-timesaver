# TS DLSS Upscaler

Upscale a picture — or a whole video batch — with **NVIDIA DLSS 5 Neural Rendering**: the same feature games use, running here on your frames. `IMAGE` in, `IMAGE` out, so a single still and a batch of decoded video frames both go straight in.

**It brings its own runtime, and by default it fetches it.** On the first run ~486 MB arrive in `models/DLSS/dlssnr/` from the upstream project's release — three files: NVIDIA's DLSSNR runtime, the Neuroframe Engine that drives it and the caller shim NVIDIA's signed snippet insists on. The download has a progress bar, and so does the processing that follows; the licence notice is printed *before* the network is touched, not after. Nothing is bundled with the pack. A file deleted later is fetched again on the next run, and `download_if_missing` off means the node fetches nothing and you place the files yourself.

**Every runtime file is checked against its hash, and a mismatch stops the node.** It does not merely read these files — it **loads `neuroframe_engine.dll` into the ComfyUI process**, so "upstream probably rebuilt something" is not an acceptable answer here: a GitHub release can be deleted and re-uploaded at the same address. If you installed a different build on purpose, tell the machine so with `TS_DLSS_SKIP_VERIFY=1`; the variable lives outside the workflow.

**Since the v9 runtime there is no worker process.** The feature is evaluated in-process through a C ABI; the engine owns the D3D12 device, the NGX feature instances, NVIDIA's optical flow and a GPU temporal stabiliser. Measured on an RTX 3080 Ti Laptop: the old v5 worker did 1.39 s per frame to 1080p, the v9 engine does 0.22 s — about six times faster for the same picture.

**Frames stay in video memory.** The engine will share memory with the caller only if the process's CUDA context was created with the blocking-sync flag — and in ComfyUI it never is, because torch brings CUDA up at server start, long before any node runs. So the node asks the driver for that flag once, before the engine starts, and says so in the log; `TS_DLSS_KEEP_CUDA_FLAGS=1` forbids it and keeps the slower road. It is worth the sentence: measured at 4K on an RTX 3080 Ti Laptop, **0.27 s per frame through video memory against 0.62 s through host memory**, with the card idle more than half the time on the latter.

**It tells you where the time went.** After every batch two lines go to the console: what ran (engine build, card, motion backend, scene resets) and the seconds per frame split into preparing, the network itself and delivering — plus which memory the frames travelled through. The network is the floor and it grows with the output: ~0.1 s per frame to 1080p and ~0.27 s to 4K, so a factor is a time budget as much as a size.

**Five modes, and 1× is not a no-op.** `2× (Performance)` is the default; `1.5×`, `1.724×` and `3×` change how big the result is. The picture is resized to that size with Lanczos and **the network re-renders it there**, which is why `1× (DLAA)` is a real mode: no resize at all, just the network on footage that is already big enough. The output is capped at 7680×4320, and asking for more names the largest factor that fits instead of failing vaguely.

**Temporal, which is where the quality comes from.** A batch of consecutive frames shares one temporal history, so detail is carried from frame to frame instead of every frame being treated as a still. Motion is no longer estimated here — the engine does it on the GPU — so the only thing the node still supplies is where the cuts are: a hard cut restarts the history rather than smearing across it. `shimmer_suppression` (0.70 by default) is that stabiliser's strength; a single picture is always rendered with it at 0. **Switch `temporal` off for a batch of unrelated pictures** — otherwise each one drags the previous one's detail behind it.

**The look controls.** `nr_style` (Default / Natural / Cinematic) and `nr_intensity` set the character; `local_tone_strength` and `local_structure_strength` how much contrast and detail come back; `skin_structure_strength` keeps faces from turning plastic. Added with v9: `nr_passes` (1–4, each pass another full evaluation), `nr_color_strength` and `tone_preservation` for how much of the network's colour and tonality reaches the result, `face_skin_protection` and `grain_preservation` — raise the last one for film scans, so the grain is kept instead of cleaned away. `dlss_model_preset` is **ignored** since v9: the engine picks the network itself, and the widget only stays so older workflows keep their other settings lined up.

**The 8-bit pipe is handled, not ignored.** The network's quality was measured through 8-bit frames, and a ComfyUI IMAGE is float. Rounding straight down turns smooth gradients into steps *before* the network sees them, and the network then sharpens the steps; `dither` (on by default) spends those bits as blue noise instead. `source_curve` is for pictures that are not display-referred SDR — log footage, PQ/HLG, a linear EXR render: they are converted to SDR before the network and converted back after, by the same curve, so the node changes the size and not the colour. Leave it at SDR for ordinary graph output.

**Windows and an NVIDIA RTX card only.** The work is done by NVIDIA's signed D3D12 runtime and there is no other implementation of it; RTX 40/50 are official, RTX 30 works on the experimental path and wants a current driver. Anywhere else the node says so instead of failing obscurely. If a native call ever wedges or reports a corrupted state, the node stops it, says so and asks for a ComfyUI restart instead of hanging the server.

> The node prints the whole notice, with the source URL and every licence, in the log before it touches the network. **Install only components you are authorised to use, from sources their licences permit.** Turn `download_if_missing` off and the node downloads nothing: place the three files under `models/DLSS/dlssnr/` yourself. The old v5 layout (`host/`, `dlss/`) is no longer read by anything and can be deleted.

**Use when:** upscaling footage or stills and you have an RTX card — especially video, where the temporal path beats a still-image upscaler run frame by frame.
