# TS Audio Preview

**Full screen.** The top-right button opens the waveform in the pack's shared fullscreen editor. Drag to select a range, adjust zoom and press Space to listen. Esc or the close button returns the panel to the node, preserving the crop and zoom.

Same waveform UI as Audio Loader, but for previewing an audio output from upstream nodes. Looped playback, crop ranges, persistent state.

**Use when:** auditioning the result of a TTS / Stem split / processing chain without saving a file.
