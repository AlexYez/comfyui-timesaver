# TS Latent Upscale

Пересчитывает уже расшумлённый латент **MiniMax H3** (видео + звук) в большем
размере. Три ноды из
[Comfyui-MMH3-UltimateUpscale](https://github.com/bbaudio-2025/Comfyui-MMH3-UltimateUpscale)
(MIT, bbaudio-2025) собраны в одну: и сам конвейер, и настройки модели
апскейла, и нарезка по времени здесь просто входы — порознь они всё равно
никому не нужны.

Для каждого куска клипа: нарезка по времени с перекрытием → апскейл видеочасти
куска трёхмерным апскейлером H3 (звук не трогается) → переякоривание
кондиционирования, причём нулевой кадр притягивается к результату предыдущего
куска → семплирование → сшивка по перекрытию. **Пик VRAM — это один кусок, а не
весь клип**, и на время работы апскейлера диффузионная модель уходит с карты:
вдвоём они не нужны ни секунды.

**Подпапки в `models/latent_upscale_models` наконец видны.** Оригинал смотрел
только в корень и возвращал голое имя файла — на этой машине он показывал 2
модели из 4 реально лежащих. Здесь список рекурсивный и показывает
`подпапка/файл.safetensors`, просматриваются все папки из
`extra_model_paths.yaml`, а имя, пытающееся выбраться за пределы своей папки,
отвергается. Апскейлер от другого семейства моделей теперь объясняет отказ, а не
падает с `Missing key(s) in state_dict`.

`chunk_length` и `temporal_overlap` обязаны быть кратны **17** — это сетка
ключевых кадров модели, — и проверяется это до запуска, а не через полчаса
счёта.

> **Пространственная нарезка на тайлы намеренно не перенесена.** В оригинале
> каждый кусок ещё и режется на тайлы; вход снят вместе с логикой. Швы тайлов
> требуют собственных настроек растушёвки, а клипу, которому нужен тайлинг,
> честнее помочь более короткими кусками.
