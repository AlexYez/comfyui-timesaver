# TS Batch Write

Записывает результат сразу, как только он готов, а не копит всё до конца прогона. Батч, упавший на 90-м задании, оставляет на диске 89 результатов, а не ничего.

**Три раскладки, и средняя замыкает круг.** `One file, blocks` разделяет результаты пустой строкой (читается обратно нодой TS Batch Prompt Loader). `One file, one line per item` схлопывает каждый результат в одну строку — её читает TS Batch Source в режиме `Lines in text file`, и файл подписей превращается в файл заданий на генерацию без единой конвертации. `One .txt per item` называет файл по картинке — раскладка датасетов подписей.

**Видеть процесс.** ComfyUI собирает превью всех итераций и отправляет их одним событием после последней, поэтому сотня картинок иначе появляется разом, в конце. Подключите сюда `image` — и текущий результат уходит через **полосу прогресса**: 47-е задание видно, пока оно 47-е.

`index 0` начинает файл заново, чтобы новый прогон молча не продолжил файл прошлого; любой другой индекс дописывает — именно это позволяет возобновлённому прогону добавиться к уже сделанному.

**Когда нужна:** любой длинный батч, результаты которого хочется иметь на диске — и перед глазами — до его окончания.
