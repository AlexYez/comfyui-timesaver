# TS Load LoRA, model only

Аналог `LoraLoaderModelOnly`. Только «model only», и это не упрощение ради экономии: модели, ради которых замок и заводился, — видео и дистилляты, а в таком графе CLIP отдельным проводом не ходит вовсе. Сила `0` не трогает модель, как и у штатной ноды.
