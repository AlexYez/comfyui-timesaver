# TS Image Studio

Полноэкранная студия: генерация, редактирование, инпейнт и апскейл
локальными моделями через нативные workflow ComfyUI. Откройте интерфейс из
ноды; выход IMAGE отдаёт результат, выбранный в галерее студии.

**Режимы:** Генерация (t2i), Редактирование (Qwen Image Edit, до 3
референсов), Inpaint (мгновенный LaMa Cleanup + диффузионный Repaint на
одном холсте), Upscale (восстановление SeedVR2 или второй проход диффузией).

**Поле промпта:** диктовка голосом, прикрепление картинки с ИИ-комбинированием,
пресеты улучшения, библиотека из 157 стилей с чипами.

**Бэкенды — обычные workflow ComfyUI** с маркерными нодами TS/Studio —
положите свой в `user/default/ts-studio/workflows/`, чтобы добавить или
переопределить встроенный.

Нажмите F1 внутри студии для полной встроенной справки.
