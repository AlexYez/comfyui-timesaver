# TS Audio Saver

Подключите AUDIO и нажмите шестерёнку рядом с цветным кружком. Выберите WAV (PCM 16 бит, 44,1 кГц), FLAC (24 бита с исходной частотой) или MP3. При выборе MP3 появится битрейт: 128, 192, 256 или 320 кбит/с, по умолчанию 320. Запустите workflow, чтобы сохранить дорожку целиком на сервере. Выделение на волне задаёт диапазон для прослушивания.

В поле имени укажите путь относительно папки output без расширения. Например, `stems/%date:yyyy-MM-dd%/vocals_%date:hh-mm-ss%`. Как в Save Image, в интерфейсе можно сослаться на виджет другой ноды через `%Название ноды.имя_виджета%`. Нода создаёт подпапки и добавляет порядковый номер. Для батча каждый элемент получает отдельный файл, `%batch_num%` подставляет индекс с нуля. Плеер показывает первую дорожку.

Для стемов поставьте по одному TS Audio Saver на каждый выход и расположите их друг под другом. Цветной кружок позволяет выбрать один из восьми оттенков или свой цвет. Цвет хранится в workflow отдельно для каждой ноды. Для точной подстройки диапазона откройте плеер на весь экран кнопкой справа.

Чтобы положить стемы в папку с названием выбранного в TS Audio Loader трека, введите в поле имени `stems/%TS_AudioLoader.file_stem%/vocals`. В остальных сейверах замените `vocals` на `drums`, `bass` или другое имя. Для файла `Баня.mp3` получится папка `output/stems/Баня/`. Подстановка относится к файлу, выбранному в интерфейсе загрузчика.
