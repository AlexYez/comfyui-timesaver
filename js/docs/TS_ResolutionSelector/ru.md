# TS Resolution Selector

Визуальный выбор соотношения сторон. Доступны 1:1, 4:3, 3:2, 16:9, 21:9, 3:4, 2:3, 9:16, 9:21 или произвольное соотношение, плюс целевой бюджет в мегапикселях. Начальное значение — **1,5 Мп**. В рабочей версии после 12.13.9 диапазон слайдера по умолчанию — **0,1–4 Мп**. В опубликованной 12.13.9 верхняя граница — **3 Мп**.

**Изменить максимум:** откройте панель **Properties** ноды и задайте **max_megapixels**, например `8`. Настройка сохраняется в workflow отдельно для каждой ноды. При уменьшении максимума текущее значение выше него уменьшается до нового предела. При открытии сохранённого workflow его разрешение сохраняется: если оно выше максимума, диапазон расширяется до этого значения.

На выходе — **IMAGE**, пустое полотно с размерами, кратными 32. Для получения latent подключите VAE Encode. Если подключить картинку, нода впишет её на полотно; с `original_aspect=True` соотношение берётся из картинки, а не пресета.

**Когда использовать:** старт генерации с фиксированной пропорцией, нормализация произвольной картинки в latent-сетку.
