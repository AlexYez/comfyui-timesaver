# TS Batch Source

Превращает папку, текстовый файл или просто число в **список заданий**. Всё, что подключено ниже, отрабатывает по разу на каждое задание — это встроенный батч-движок самого ComfyUI: списковый вход заставляет ветку выполниться N раз, и каждый прогон независим от остальных.

Независимость здесь и есть смысл. Модель, пишущая подписи, получает на каждую картинку свежий разговор, а не один контекст, растущий сто картинок подряд.

Режимы: `Images in folder` (естественный порядок — `img2` идёт перед `img10`), `Lines in text file`, `Count only`. Выходы: `item` (путь / строка / номер), `index`, `total`, `seed`.

**Зачем выход seed.** Виджет seed на самой модели хранит одно число на все сто вызовов — сто итераций одного задания вернули бы сто одинаковых ответов. Этот выход выдаёт каждому заданию свой производный seed: воспроизводимый от базового и непохожий на соседние.

**Возобновление.** `start_at` пропускает сделанную часть и сохраняет исходную нумерацию, поэтому TS Batch Write дописывает файл, а не начинает его заново. `limit` ограничивает прогон.

⚠️ **Отдаёт пути, а не картинки** — намеренно. Сотня кадров 4K, переданная изображениями, легла бы в кэш выхода (около 10 ГБ) ещё до первой записанной подписи. TS Batch Load Image читает их по одной, и пик остаётся размером в один кадр.

**⚠️ `one_per_run` — прочтите до запуска длинного батча.** Со списком ComfyUI **доводит до конца каждую копию одной ноды и лишь затем берётся за следующую** (замерено на живом сервере: загрузчик отчитался по заданиям 1, 2, 3 — и только потом писатель по 1/3, 2/3, 3/3). Отсюда два следствия: результаты попадают на диск только после того, как модель сделала всё, а нода, пишущая метаданные поштучно — TS Image Prompt Injector, — оказывается затёрта последним заданием ещё до сохранения, и все картинки получают один и тот же промпт.

Включите `one_per_run` и поставьте в очереди ComfyUI **Batch count** равным числу заданий. Тогда каждый прогон — полный проход по графу: картинка сгенерирована, подписана и сохранена до начала следующего задания. Чуть медленнее — и единственно верно, когда нужно видеть результаты по мере готовности или иметь честные метаданные у каждого файла.

**Типичная цепочка:** TS Batch Source → TS Batch Load Image → TS Qwen 3 VL → TS Batch Write.

**Когда нужна:** собрать датасет подписей по папке или сгенерировать N уникальных промптов, каждый — отдельной итерацией.
