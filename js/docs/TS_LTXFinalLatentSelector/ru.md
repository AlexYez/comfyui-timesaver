# TS LTX Final Latent Selector

Выбирает латент первой или второй стадии **до** декодирования, вместо того чтобы
декодировать оба и один выбросить. Входы ленивые, поэтому выключенный апскейлер
перестаёт стоить времени сэмплера, а не только декодера, — а один decode дальше по графу
означает одно место, где происходит HDR-преобразование.

**Когда нужна:** в графе есть переключатель двух стадий. Её стоит поставить и без HDR.
