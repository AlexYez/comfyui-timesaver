# Visual Enhancer v21 для TS DLSS Upscaler

Это зарезервированное место для отдельно устанавливаемого приложения. Бинарные файлы не входят в Git и не скачиваются нодой.

1. Скачайте полный архив [официального Visual Enhancer v21.0](https://github.com/Merserk/dlss5-visual-enhancer/releases/tag/v21.0).
2. Внутри папки установленного `comfyui-timesaver` создайте `runtime/visual-enhancer/v21` и распакуйте туда весь архив. Не оставляйте дополнительный уровень вложенности:

```text
comfyui-timesaver/
  runtime/visual-enhancer/
    README.md
    v21/
      VE_CLI.exe
      Visual Enhancer.exe
      bin/
      Qt6Core.dll
      ...остальные файлы официального архива
```

3. В TS DLSS Upscaler выберите `v21 (external CLI)`. Поле `v21_directory` оставьте пустым.

Простая инструкция также находится в tooltip поля **«движок»**. Если папка отличается, укажите только относительный путь **от корня пака**. Абсолютные пути и выход за пределы пака отклоняются. Поля и их порядок не изменены; v9 остаётся по умолчанию.

При переносе всей портативной ComfyUI на другой диск эта папка перемещается вместе с установленным паком. Скачанный архив и Git-обновления пака — разные вещи: `git pull` не устанавливает, не обновляет и не удаляет приложение. Не удаляйте установленный клон ради обновления.

Код проверяет контрольные суммы конкретной поддерживаемой сборки v21.0. Чтобы заменить её другой версией, потребуется совместимое обновление адаптера, а не только переименование папки. Дополнительные VisionNext/RazorNext-веса для режима DLSS NR не требуются.
