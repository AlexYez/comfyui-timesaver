# Пересоздать ноду — сброс на умолчания, провода на месте

Пользовательская функция интерфейса, отдельной ноды нет. Исходник: [ts-recreate-node.js](../../js/utils/ts-recreate-node.js). Численные замеры ниже сохранены из прежнего README как исторические примеры, не гарантия для любого графа.

Правый клик по любой ноде → **Пересоздать ноду**. Нода встаёт заново, как только что поставленная из меню: все значения на умолчаниях, **название, цвет, размер и свойства — тоже**. Остаются место на холсте, номер ноды (ссылки на него в графе не едут), режим (байпас или выключение — это состояние графа, а не настройка ноды) и **все провода, включая точки на них**. Лечит ноду, сохранённую старой версией пака или ComfyUI, и просто сбрасывает накрученное. Если выделено несколько нод и клик пришёлся по одной из них, пересоздаётся всё выделение. Команда есть и в палитре ComfyUI; **Ctrl+Z** возвращает прежнюю ноду.

Провод ищет у новой ноды гнездо с тем же именем, а если вход переименовали в новой версии — гнездо на том же месте и того же типа. Входы, которые появляются по мере подключения (картинки у Qwen Image 2.1: `image_1`, `image_2` …), подключаются по порядку. **Не нашлось гнездо хотя бы для одного провода — нода остаётся как была**, со своими значениями и всеми проводами, а сообщение называет, что не сошлось: ни один провод не теряется. Сабграфы и ноды, которых в этой сборке нет, в меню пункта не получают.
