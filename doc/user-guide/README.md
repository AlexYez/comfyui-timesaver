# Дополнительные пользовательские функции

Команды frontend не являются публичными нодами и поэтому вынесены отдельно от встроенного node help.

| Возможность | Описание |
|---|---|
| [Tidy up / RU](layout.ru.md) · [EN](layout.en.md) | Логическая раскладка, маршрутизация связей и Pack as tiles с областью моделей слева. |
| [Recreate node / RU](recreate.ru.md) · [EN](recreate.en.md) | Восстановление ноды с исходными значениями и сохранением совместимых связей. |
| [Запертые модели / RU](locked-models.ru.md) · [EN](locked-models.en.md) | Общая схема .tsmodel, пределы защиты и связь с родными загрузчиками. |
| [Пример HDR workflow](../../example_workflows/08_ltx25_native_hdr.json) | Готовая HDR-половина графа; прочитайте заметки внутри workflow, основной LTX-граф подключается отдельно. |

Настройки отдельных нод — [справочник](../nodes/README.md); установка и диагностика — [operations](../operations/README.md).
