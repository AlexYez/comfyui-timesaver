# Лицензии, источники и благодарности

Код и документация пака распространяются по [MIT](../LICENSE.txt). Это не меняет лицензии стороннего кода, весов, NVIDIA SDK и отдельно устанавливаемых приложений. Проверяйте файлы лицензий конкретных компонентов и справку ноды до использования.

Основные источники, указанные в прежнем README:

- [ComfyUI](https://github.com/comfyanonymous/ComfyUI) — граф и V3 API.
- [BiRefNet](https://github.com/zhengpeng7/BiRefNet) — удаление фона.
- [LaMa](https://github.com/advimman/lama) — inpainting.
- [Whisper](https://github.com/openai/whisper) — распознавание речи.
- [Demucs](https://github.com/facebookresearch/demucs) — один из поддерживаемых движков разделения музыки; не единственный современный backend.
- [Silero](https://github.com/snakers4/silero-models) — TTS и работа с русским текстом.
- [Qwen](https://github.com/QwenLM/Qwen3-VL) — семейство vision-language моделей.
- [RIFE](https://github.com/megvii-research/ECCV2022-RIFE) и [FILM](https://github.com/google-research/frame-interpolation) — интерполяция кадров.

У DLSS и RTX есть дополнительные внешние компоненты: [DLSS](../js/docs/TS_DLSSUpscaler/ru.md), [RTX](../js/docs/TS_RTX_Upscaler/ru.md). Полная атрибуция vendored-компонентов остаётся рядом с их исходниками; этот список не заменяет их лицензии.
