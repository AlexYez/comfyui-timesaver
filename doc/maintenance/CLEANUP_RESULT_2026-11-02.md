## Где лежат данные и как вернуть

Манифест — локальный `archive/2026-11-02/MANIFEST.md`: одна строка на исходный пункт, исходный/новый адрес, размер, Git-статус и причина. `JOURNAL.json` фиксирует состояния, `FILES_SHA256.json` — каждый файл и его контрольную сумму. Архив намеренно исключён из Git; эти адреса не обещают наличие архивных данных в чужом клоне.

Для восстановления перенесите нужный путь из партии обратно к корню проекта. Если по старому адресу появился новый файл, сначала сравните его с архивным; не перезаписывайте автоматически. Проверенное содержимое архива не заменяет текущие исходники и документацию.

Правило `/archive/` уже находилось в HEAD до операции; `git check-ignore` подтвердил исключение. Нового изменения только для этого правила не требовалось. Все перенесённые файлы были неотслеживаемыми: `git rm --cached` не понадобился, новых файлов архива Git не предлагает. Прежние незакоммиченные изменения сохранены: SHA256 всех 768 отслеживаемых файлов рабочего дерева совпали до/после архивации.
