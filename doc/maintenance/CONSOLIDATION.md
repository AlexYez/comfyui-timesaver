## Переносы и объединения

- Подробные описания нод остаются в существующем `js/docs`: корневые README теперь ссылаются на [каталог](../nodes/README.md), а изображения — на [галерею](../nodes/screenshots.md). Не создана третья копия node help.

- CLAUDE превращён в указатель на AGENTS. Инженерные правила и причины перенесены в [engineering](../engineering/README.md); архитектура и тема разделены, прежние адреса сохранены короткими указателями.
- CHANGELOG превращён в указатель по версиям; исходные релизные сообщения сохранены в [истории релизов](../history/releases/README.md). Два старых аудита разделены с сохранением исходных выводов, их корневые адреса ведут к [истории](../history/README.md).
- 50 тем требований/истории и 112 инженерных тем распределены по каталогам. Объединены три записи lifecycle, две оконные и две языковые. Дословные поправки не заменены пересказом. Большие DLSS, DOM, media, Ideogram, HDR, tests и Studio persistence разделены на hub и части.
- Удалены прежние плоские копии тем после переноса; данные не удалялись как «ненужная память». Отменённые требования и снятые функции маркированы историей. Подробности: [owner](memory-owner-findings.md), [engineering](memory-engineering-findings.md).
- `.gitignore` больше не скрывает постоянную память, AGENTS, CLAUDE и каноническую архитектуру. Исключения для токенов, моделей, кэшей, тестовой лаборатории и архивных zip сохранены.
