# 12.13.2

Историческая запись релиза: команды, пути и утверждения ниже относятся к состоянию этой версии. Актуальный порядок работы — в [operations](../../operations/README.md).

### TS Batch Source: батч по любым файлам, вложенные папки, промпты из картинок

- **`Files in folder` вместо `Images in folder`.** Нода отдаёт пути, поэтому
  берёт файлы любого типа. Новый список `file_types` — All / Images / Videos /
  Audio — сужает выбор ровно до форматов, которые открывает соответствующая
  загрузка. Новый переключатель `include_subfolders` обходит и вложенные
  папки; порядок естественный по каждому уровню пути.
- ⚠️ **Старые графы с `Images in folder` работают как прежде** — берут только
  картинки, чтобы лежащие рядом `.txt`-подписи не поехали в загрузчик
  картинок. В списке режимов старого имени больше нет; новые входы
  необязательные и стоят в конце.
- **Режим `Prompts from images in folder`** — вместо картинок отдаёт
  позитивные промпты, с которыми они сделаны: метаданные ComfyUI (граф, через
  переключатели, `StringConcatenate`, TS Super Prompt, TS Style Prompt
  Selector), A1111 / Forge / Civitai, NovelAI. Картинки без промпта
  пропускаются; текст, написанный LLM во время прогона, в файле не хранится —
  вместо него нода не подсунет инструкцию, данную модели.

### TS Video Loader и TS Audio Loader принимают путь проводом

Новый необязательный вход `path` (сокет без виджета, последним — сохранённые
графы его не замечают). Подключите `item` от TS Batch Source — и загрузка
пройдёт по папке роликов или звука, по файлу на задание. Файл с провода
главнее выбранного в ноде; подрезка с таймлайна к нему **не применяется** (её
ставили на другом файле). Нода показывает, что файл идёт по проводу, а после
прогона — какой именно.
