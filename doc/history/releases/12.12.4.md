# 12.12.4

Историческая запись релиза: команды, пути и утверждения ниже относятся к состоянию этой версии. Актуальный порядок работы — в [operations](../../operations/README.md).

### TS Int Slider и TS Float Slider: человеческие диапазоны, без отрицательных

Новая нода больше не копирует в свои свойства жёсткие границы схемы: панель
свойств показывала −1 000 000 000 … 1 000 000 000 (Float) и ±2 147 483 648
(Int), и ползунок растягивался на всё это. Теперь новая Float-нода ходит
0 … 10 с шагом 0.1, Int — 0 … 2048 с шагом 8; свой диапазон задаётся в
свойствах, как и раньше.

⚠️ **Отрицательные значения убраны.** Схема теперь: Float 0 … 10 000,
Int 0 … 100 000. Нода, у которой в сохранённом графе стоит отрицательное
значение, получит своё значение по умолчанию; минимум в свойствах ниже нуля
поднимается до нуля. Старые ноды с границами ±1e9 / ±2³¹ при открытии получают
рабочий диапазон, расширенный так, чтобы текущее значение в нём осталось.

Попутно исправлено: при загрузке графа свойства ноды приходят по одному
раньше значения виджета, и слайдер мог переписать диапазон по значению по
умолчанию. Теперь диапазон берётся из сохранённого графа целиком.

### TS LoRA Loader: замена LoRA щелчком по имени, колёсико в списке

Щелчок по имени выбранной LoRA открывает полный список установленных LoRA —
как у родной Load LoRA: текущая подсвечена и прокручена в видимую область,
выбор заменяет файл, а сила, выключатель и режим строки остаются. Колёсико
мыши над списком теперь его прокручивает; раньше любой поворот колёсика
список закрывал. Колёсико над холстом по-прежнему закрывает его.

⚠️ Раньше щелчок по имени выключал строку. Выключение теперь только
квадратиком-выключателем слева от имени.

### TS LoRA Unmerged: MiniMax H3 на ComfyUI 0.38.2

На ComfyUI 0.38.2 генерация с MiniMax H3 и TS LoRA Unmerged (в том числе через
режим «ветка» TS LoRA Loader) падала с `'list' object has no attribute 'dtype'`:
ядро стало подавать модели латент списком — видео и звук. Исправлено.
