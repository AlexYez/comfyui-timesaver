# 12.13.7 — 2026-11-02

## Gemma / LiteRT-LM

Рекомендуемый runtime обновлён до `litert-lm-api==0.19.0`. В Python-окружении
ComfyUI его можно установить командой `python -m pip install --upgrade litert-lm-api==0.19.0`.
Адаптер использует новый SpeculativeDecodingConfig, сохраняя совместимость со
старым API. MTP остаётся выключенным, автоматическая выгрузка включена по умолчанию.

На существующих E2B/E4B локальный benchmark показал ускорение декодирования без
MTP примерно на треть. Это не ускорение всего workflow или гарантия точного
распознавания: [методика и результаты](../litert-019-2026-11-02.md).

Обновлены пять существующих системных пресетов: LTX/H3 и три музыкальных/SFX.
Уточнены работа с референсом, стиль, камера и запрет выдуманных музыкальных
деталей; удалён жанровый словарь, который мог навязывать готовые ответы. Имена,
порядок и параметры генерации пресетов сохранены.

В справке и tooltip указаны проверенные ограничения анализа музыки, звуков и
хронологии кадров. Распознавание русской речи работает на обеих моделях;
редкие названия могут быть ошибочными. Подробность музыкального ответа не
гарантирует точность: [комбинированные проверки и эталон владельца](../litert-combined-2026-11-02.md).

## Переносимая установка Visual Enhancer v21

TS DLSS Upscaler ищет полное приложение в `runtime/visual-enhancer/v21` внутри
пака. Пустой `v21_directory` выбирает эту папку; принимаются только относительные
пути внутри пака. Абсолютные пути и выход за его пределы отклоняются.
Простая ручная установка описана в tooltip выбора движка. v9 остаётся по умолчанию.
Приложение и модели v21 не входят в дистрибутив и не скачиваются нодой.
