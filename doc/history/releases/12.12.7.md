# 12.12.7

Историческая запись релиза: команды, пути и утверждения ниже относятся к состоянию этой версии. Актуальный порядок работы — в [operations](../../operations/README.md).

### Вкладки левого меню — в настройках пака

В **Настройки → TS Timesaver → Interface** появилась галочка на каждую вкладку
левого меню ComfyUI: «Ассеты», «Библиотека нод», «Библиотека моделей», «Рабочие
процессы», «Приложения» — и на вкладки других расширений (их галочка появляется
вместе с ними). Выключено — вкладка уходит из меню, открытая панель сначала
закрывается; включено — возвращается на своё прежнее место. Применяется сразу,
без перезагрузки. Кнопки под вкладками («Шаблоны», «Центр поддержки»,
«Настройки») не трогаются.

### TS Batch Source: промпты из папки, по файлу на промпт

Новый режим **Text files in folder**: каждый `.txt` / `.md` в папке — одно
задание, весь текст файла (переносы строк внутри сохраняются), в естественном
порядке (`2` перед `10`); пустые файлы пропускаются. Вместе с `one_per_run` и
Batch count у кнопки Run даёт генерацию картинка за картинкой с промптом в
метаданных через TS Image Prompt Injector. Режим дописан в конец списка,
умолчание прежнее.

### TS Files Downloader: кнопка и прогон больше не расходятся

Исправлено: кнопка «Download Models» отказывала строке с папкой вида
`/loras/qwen2` («the button downloads into model folders only»), хотя запуск
графа ту же строку качал в `models/loras/qwen2`. Так было в 4-й строке списков
графов Qwen 2.1. Теперь косая черта в начале понимается одинаково; буква диска и
сетевые пути кнопке по-прежнему запрещены.
