## Зависимости LiteRT и RTX

Extra RTX требует NVIDIA VFX `>=0.2.0.0,<0.3` для совместимости с официальным
паком Nvidia VFX Nodes. Подсказка установки ведёт на индекс NVIDIA вместо
заглушки на PyPI. Для импорта `litert_lm` предлагается `litert-lm-api==0.19.0`,
для `cv2` — `opencv-python-headless`, как в core requirements.

[Справка LiteRT](../../../js/docs/TS_SuperPromptRT/ru.md) объясняет конфликт
старого CLI 0.16.1 с API 0.19.0: если CLI/builder не используются отдельно,
удаляют их, а рабочий API сохраняют. Нативные SDK остаются необязательными.

Исправления конкретного Python-окружения владельца, включая замену CUDA wheels
под Torch 2.11, описаны в [инженерной памяти](../../../project_memory/engineering/runtime_dependencies.md).
Они не выполняются автоматически при обновлении пака.
