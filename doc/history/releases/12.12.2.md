# 12.12.2

Историческая запись релиза: команды, пути и утверждения ниже относятся к состоянию этой версии. Актуальный порядок работы — в [operations](../../operations/README.md).

### TS LoRA Loader: у каждой строки — режим «слияние» или «ветка»

Рядом с именем LoRA появилась метка режима. `слияние` — как было: штатный
LoraLoaderModelOnly, LoRA вливается в веса, во время работы бесплатно.
Нажатие переключает строку на `ветку`: эта LoRA применяется боковой веткой без
слияния — так же, как в TS LoRA Unmerged, на своём месте в цепочке. Округление
на весах bf16/int8 ничего из LoRA не съедает; цена — около 10–25% времени шага
и веса LoRA в видеопамяти на время выборки. Имеет смысл для маленьких
турбо-LoRA; только обычные линейные LoRA (DoRA, LoKr, LoHa отклоняются).

Графы не задеты: режим хранится в том же списке, входы ноды прежние, а у всех
сохранённых графов строки открываются на `слиянии`. Поле пишется только у строк
в режиме `ветка`, так что остальные сохраняются символ в символ как раньше.

Границы силы у TS LoRA Unmerged расширены до штатных (−100…100, шаг 0.01):
строка списка разворачивается то в штатный загрузчик, то в неё, и сила,
принятая одним, не должна отвергаться другим.

### TS Prompt Library: удаление фона с прозрачностью и поиск прямо в ноде

Новый пресет **O13 «Удаление фона: главный объект на прозрачном фоне»** у обеих
моделей. Объект описывать не нужно — модель находит главный сама (для
конкретного объекта из нескольких остаётся O12). У Qwen Image 2.1 промпт
построен на официальной формуле прозрачности, и результат приходит с настоящей
альфой: VAE модели декодирует RGBA, штатный Save Image пишет PNG с прозрачностью.
В примечании сказано, как не потерять альфу по дороге и как подать на вход
картинку, у которой прозрачность уже есть (Join Image with Alpha). У Klein альфы
нет — объект выводится на белый фон под TS Remove Background.

**Поиск теперь и в обычном режиме ноды**, а не только во весь экран. Поле над
промптом: найденное встаёт на место карточки, ↑ / ↓ листают, Enter или щелчок
выбирают, Esc сбрасывает. При открытии окна поле с запросом переезжает в колонку
каталога. Ищет по коду, названию, группе, описанию и тексту промпта на обоих
языках, «ё» = «е»; при активном поиске ‹ › и стрелки ходят только по найденному.

Графы не задеты: ключи пресетов прежние, O13 добавлен в конец своей группы.

### TS Shifted Sigmas: список шагов можно вставить из описания модели как есть

Поле шагов теперь понимает дроби (`1 / 6`, `1 / 12`) и квадратные скобки — так
списки печатает Viggle. Расписание v0.3 на 9 шагов вставляется одной строкой.
Прежние записи читаются как раньше.

В README описан режим viggle-turbo v0.3 на 9 шагов (7 с турбо-LoRA, 2 базовой
моделью) штатными нодами: `SplitSigmas` и два `SamplerCustomAdvanced`.
