# 12.13.3

Историческая запись релиза: команды, пути и утверждения ниже относятся к состоянию этой версии. Актуальный порядок работы — в [operations](../../operations/README.md).

### H3 Regenerate: уточнение видео, стартовый кадр и склейка кусков

- **TS H3 Regenerate Model** подключает объединённую LoRA Open-H3-Regenerate-2K
  и ветки Sharp к отдельной чистой модели H3. Из референс-чекпоинта читается
  только небольшая таблица; вторая модель целиком на GPU не загружается.
- **TS H3 Regenerate** увеличивает латент и уточняет его за 2 или 3 шага.
  Denoise регулирует перерисовку, исходный звуковой латент сохраняется.
  Необязательный стартовый кадр кодируется обычным H3 video VAE в итоговом
  разрешении. Для него можно подготовить отдельную картинку, сохранив больше
  деталей, чем на первой стадии. Режим сохранения персонажа экспериментальный.
- **Продолжение с закреплением перекрытия** сохраняет готовую часть предыдущего
  куска вместо смешивания двух разных версий. Если в конце остаётся слишком
  короткая дорисовка, куски перераспределяются по временной сетке H3 в пределах
  выбранной длины. Это убирает отдельный пятикадровый хвост после кадра 221 в
  ролике на 226 кадров. Отсутствие видимых швов и сохранение движения требуют
  проверки на конкретном видео.
- **TS H3 Fast VAE Decode** поддерживает быстрый декодер NVIDIA в FP32 и INT8
  convrot; обычный video VAE можно подключить для отката при нехватке памяти.
- Исправлена проверка размеров, приходящих проводами: неизвестные до запуска
  значения больше не вызывают ошибку валидации. В **TS Latent Upscale** добавлен
  denoise.

### Состояние нод, звук и раскладка workflow

- **TS Int Slider / TS Float Slider:** выбранное значение сохраняется при
  восстановлении workflow, в том числе с нестандартным default и шагом.
- Исправлена передача скрытых параметров DOM-нод внутри subgraph.
- **TS Audio Loader:** поздний ответ по предыдущему файлу больше не заменяет
  текущий файл и его настройки. В Audio Loader и Audio Preview добавлен общий
  полноэкранный редактор для выбора участка и масштабирования волны.
- **TS Batch Write:** допустимые имена отдельных TXT сохраняются без удаления
  скобок и другой пунктуации; небезопасные имена отклоняются, а не сводятся к
  совпадающим именам файлов.
- **Tidy Up / Pack as Tiles:** загрузчики моделей, LoRA, VAE и модели латентного
  апскейла размещаются отдельной областью слева с учётом связей.
- **TS Video Saver:** результат фонового workflow восстанавливается в ноде при
  возвращении на вкладку. Запись файла выполняется сервером; повторный Run
  для обновления превью не требуется.
- **TS DLSS Upscaler:** начальное значение детализации кожи снижено с 2 до 0,
  чтобы сеть меньше дорисовывала поры и усиливала мелкий шум декодера.
  Сохранённые workflow продолжают использовать свои значения.

Существующие входы и их порядок сохранены; новые режимы H3 Regenerate
необязательны и по умолчанию выключены либо используют прежнюю склейку.
