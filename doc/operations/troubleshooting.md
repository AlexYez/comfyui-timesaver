# Диагностика обычных сбоев

Начните с [логов и окружения](environment.md), затем выберите симптом. Не переустанавливайте пак и не удаляйте пользовательские данные без установленной причины.

| Симптом | Что проверить | Источник |
|---|---|---|
| Нода не появилась | Startup error, правильный каталог custom_nodes, версия ComfyUI, `TS_VERBOSE_STARTUP=1`. Считайте реальные node_id, не файлы Python. | [Loader](../../__init__.py), [контракты](../../tests/contracts/node_contracts.json). |
| `ModuleNotFoundError` | Установлены ли зависимости **тем Python, который запускает ComfyUI**; optional-пакет может требоваться только одной ноде. | [Установка](development.md), [dependency manager](../../ts_dependency_manager.py). |
| Правка на C: не видна в ComfyUI | Установленный клон отдельный: сравните содержимое нужного файла. Для Python нужен разрешённый рестарт, для JS — обновление страницы. | [Окружение](environment.md). |
| Нет кнопки Manager | Проверьте launcher flags и состояние самого ComfyUI Manager; не приписывайте проблему паку без воспроизведения. | [Память по Manager](../../project_memory/engineering/reference_manager_visibility.md). |
| ffmpeg не найден | Проверьте `imageio-ffmpeg` в окружении ComfyUI. Его бинарник используется первым, PATH — запасной путь. | [Резолвер](../../nodes/_ffmpeg.py). |
| NVIDIA VFX: нет `QualityLevel` | Сверьте установленную версию `nvidia-vfx` с официальным VFX-паком. TS RTX поддерживает API 0.1/0.2; установка библиотеки описана в справке. Не обновляйте DLL в работающем процессе. | [TS RTX Upscaler](../../js/docs/TS_RTX_Upscaler/ru.md). |
| DLSS v21 сообщает про настройку/диапазон | Смотрите tooltip конкретного входа: v9-only параметры требуют дефолтов; v21_directory должен указывать на полную официальную сборку. | [TS DLSS Upscaler](../../js/docs/TS_DLSSUpscaler/ru.md). |
| Видео видно в превью, но «не сохранилось» | Проверяйте новый файл и время изменения на диске output, затем backend history/ошибку энкодера. Переключение браузерной вкладки не является доказательством сохранения. | [Video Saver](../../js/docs/TS_VideoSaver/ru.md). |
| Вставленная картинка объявлена отсутствующей | Проверьте реальный файл и версию ядра; пак расширяет список LoadImage подпапками input. Не перемещайте файлы наугад. | [Точечная заплатка](../../ts_pasted_media_fix.py). |
| OOM | Уменьшите разрешение/пачку, изучите настройки выгрузки конкретной модели; пониженная точность доступна не на всех платформах. | [Каталог нод](../nodes/README.md). |

Пак имеет точечный Windows Proactor guard; он отключается `TS_DISABLE_PROACTOR_GUARD=1` и не должен скрывать неизвестные исключения. Код и границы — [compat/proactor_guard.py](../../compat/proactor_guard.py). Не меняйте политику event loop ради тишины в консоли.

Перед обращением по ошибке соберите версию пака и ComfyUI, название ноды, точный traceback, небольшой воспроизводимый workflow и факт появления выходного файла. Токены, приватные ссылки и личные данные из отчёта удалите.
