# Работа с паком

Откройте один нужный документ. Пак подключается к ComfyUI, отдельного сервера и сборки JavaScript у него нет.

| Документ | Содержание |
|---|---|
| [Разработка и установка](development.md) | Чистый клон, Python окружения ComfyUI, зависимости, запуск и обновление. |
| [Проверки](testing.md) | Что доступно в клоне, локальная лаборатория, ограничения полного suite и CI. |
| [Релиз](release.md) | Версия, changelog, выбор файлов, коммит, push, Registry и установленный клон. |
| [Окружение и данные](environment.md) | Пути, модели, конфигурация, секреты и источники логов. |
| [Диагностика](troubleshooting.md) | Нет ноды, import error, старый frontend, ffmpeg, DLSS и NVIDIA VFX. |

Перед изменениями прочитайте [AGENTS.md](../../AGENTS.md). В текущей задаче меняются только документы; commands ниже — инструкции для будущей работы, а не сообщение о выполненных действиях.
