## Данные во время работы

Пак использует `folder_paths` ComfyUI для input/output/temp и model folders; пример кода — [медиа-энкодер](../../nodes/video/media/_encode.py). Фактические каталоги могут быть переопределены установкой ComfyUI.

В обычной установке пользователя ожидают каталоги input, output, temp, models и user самого ComfyUI. Это **runtime-данные**, не каталоги внутри данного Git-репозитория. Сохраняемые workflow живут в пользовательском каталоге ComfyUI; точный профиль определяется хостом.

Параметры ноды обычно хранятся в workflow. Дополнительные browser preferences могут храниться в localStorage: например, предпочтения звука Video Saver использует [его frontend](../../js/video/saver/_video_saver.js). Это не замена сохранению workflow и не источник постоянной проектной памяти.

Пользовательские пресеты Ideogram создаются во время работы и исключены из Git; их размещение определяет [helper](../../nodes/ideogram/_ideogram_helpers.py). Переносите их отдельно при смене машины. Их содержимое — пользовательские данные, не часть типовой установки.

## Логи и диагностика

Пак пишет в стандартный Python logging процесса ComfyUI: [загрузчик](../../__init__.py) использует logger `TimesaverVFX_Pack`, отдельные ноды — свои logger. Собственного обязательного log-файла у пака нет.

Для полного отчёта загрузки задайте `TS_VERBOSE_STARTUP=1` **до** запуска сервера. Это увеличивает подробность диагностического вывода, не меняя граф.

На установленном ComfyUI владельца журнал консоли доступен по `GET /internal/logs/raw`: JSON с `entries[].m`. Этот маршрут предоставляет хост ComfyUI, а не Timesaver; для другой версии хоста наличие следует проверить. Нельзя объявлять старый файл `latest.log` журналом текущего процесса без проверки способа запуска.

Браузерные ошибки смотрите в DevTools Console и Network. После изменения JS проверьте фактический ответ по `/extensions/comfyui-timesaver/` и нужному пути файла; Python после редактирования на диске остаётся старым в работающем процессе до рестарта.

## Секреты и тяжёлые данные

Файлы `.huggingface`, `.openrouter`, HF cache, env-токены и browser credentials не включайте в документацию/коммит. Пользовательские файлы, веса моделей и официальное внешнее приложение Visual Enhancer также не входят в репозиторий. Это необходимые внешние данные/зависимости, а не скрытые проектные знания. Их установка объясняется в справке конкретной ноды; содержимое токенов никогда не копируется.

Старые архивы снятых нод были локальным удобством. Надёжный источник снятого кода — Git history, не файл на диске владельца. Тесты и инструменты локальной лаборатории описаны с ограничениями в [testing.md](testing.md).
